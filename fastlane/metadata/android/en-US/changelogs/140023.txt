内部分发版。内置提供方的详情页常驻「安装与升级」区块，按安装方式列出可复制的安装命令和升级命令；一键升级的命令正常退出但版本没变时，不再显示为升级成功；macOS 上用 Homebrew 装的 Claude Code 可以一键升级。

关于升级： 「安装与升级」区块只需要升级 App。「版本没有变化」的判定和 Homebrew 版 Claude Code 的一键升级需要主机也升级到这一版；连接旧主机时，这两种情况仍显示为升级成功。

Added
- 内置提供方的详情页新增「安装与升级」区块，按安装方式分标签列出安装命令和升级命令，每条可复制
- Copilot 和 OpenCode 新增安装命令、升级命令和官方文档链接
- 详情页的一键升级失败时，提示按「安装与升级」里的命令手动升级

Changed
- 提供方装好以后「安装与升级」区块仍然显示，取代只在未安装时出现的安装指引
- 「安装与升级」区块默认选中适用于主机系统的第一种安装方式
