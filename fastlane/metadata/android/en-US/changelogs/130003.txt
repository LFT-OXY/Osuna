内部分发版。输入框里选中的文件和 skill 变成行内块；消息里可以 @ 其他智能体，由当前智能体派出子智能体；Claude Code 和 Codex 可以切换到第三方接口；设置 → Providers 重新布局。

关于升级： @ 智能体、子智能体派发组和第三方接口需要 App 和 daemon 都升级到这一版。连接旧 daemon 时，@ 列表的智能体分组置灰并提示更新 Host，提供方详情里不显示第三方接口。@ 智能体还需要在 设置 → Host → Agents → 编排 里打开「启用 Osuna tools」，已在运行的智能体要重新加载才生效。

行为变化： 子智能体请求权限时改为交给你在子会话里批准，父智能体不再代批。以前靠父智能体自动批准的无人值守编排，现在会停在等待批准。

Added
- 从 @ 列表选中的文件、文件夹和图片在输入框里显示为行内块，方向键和退格整块处理（桌面端和 Web 端）
