内部分发版。第三方接口改为主机上所有 Agent 共用：可以同时开着多家接口，Claude Code 和 Codex 经主机内置的中转站发请求，按模型名挑接口，一家额度用完或出错时自动换到有同名模型的下一家；只有 OpenAI 格式地址的接口也能给 Claude Code 用，只有 Anthropic 格式地址的接口也能给 Codex 用。

关于升级： 第三方接口需要 App 和主机都升级到这一版。新 App 连接旧主机时，提供方页的第三方接口一栏提示更新主机。旧 App（包括官方 Paseo 手机 App）连接新主机时仍是每个提供方一家启用接口的旧界面，只看得到不带接口名的模型名。

行为变化：

- 原来按提供方保存的接口升级后自动换算成主机共用的接口；第一次保存后存成新格式，退回 0.15.x 的主机读不了
- 总开关开着时，终端里的 Claude Code 和 Codex 每个请求都经过主机，主机不在运行就连不上；退回旧版本前先关掉总开关
