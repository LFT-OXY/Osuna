内部分发版。设置 → 主机 → 提供方改为「列表 → 详情」两级，内置提供方显示 CLI 版本并可一键升级；价格表分成「自定义价格」和「LiteLLM 价格」两组；简体中文界面补齐漏翻并统一术语。

关于升级： CLI 版本和一键升级需要 App 和主机都升级到这一版。连接旧主机时，提供方页不显示版本和升级按钮，其余照常。

行为变化： 默认启用的提供方改为 Claude Code、Codex、Pi 和 Oh My Pi；Copilot 和 OpenCode 改为默认关闭。config 里已经写了 enabled 的提供方不受影响。要重新打开 Copilot 或 OpenCode，在 设置 → 主机 → 提供方 里打开它的开关，或在 config.json 的 agents.providers 下写 "opencode": { "enabled": true }。

Added
- 内置提供方在列表行和详情页显示已安装的 CLI 版本
