# Osuna plugin documentation

Choose the documentation that matches your Osuna release. The plugin API is experimental and can
change between releases.

## [Osuna v0.7 — Current](/docs/plugins/v0.7)

Build and maintain plugins for the latest stable Osuna release.

## [Osuna v0.8 — Beta](/docs/plugins/v0.8)

Build plugins for Osuna 0.8 beta, with separate client and server entries. Existing plugin authors should
follow the [v0.8 migration guide](/docs/plugins/v0.8/migration).
