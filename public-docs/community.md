# Related projects

These projects are related to Osuna and built by the community.

## Plugin directory

[osuna.cafe](https://osuna.cafe) is a community-run directory of Osuna plugins. Listings are generated
from each plugin's public repository, so it is the fastest way to see what people are building and to
publish your own. It is independent of the Osuna project and nothing on it is reviewed or endorsed by
us, so read a plugin's source before installing it.

## Tools and integrations

| Project                                                                                      | What it does                                                                                                                         |
| -------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| [Osuna for VS Code](https://marketplace.visualstudio.com/items?itemName=hinnes.osuna-vscode) | Opens the matching Osuna project or worktree in VS Code and adds agent chat, file mentions, and editor links.                        |
| [VS Code Web plugin](https://github.com/itsjustanks/osuna-plugin-vscode-web)                 | Opens a live Osuna worktree in `vscode.dev` through a VS Code tunnel, including workspaces on headless hosts.                        |
| [Osuna Icon](https://github.com/gpambrozio/osuna-menubar)                                    | Shows workspace status across Osuna hosts in the macOS menu bar and opens a workspace with one click.                                |
| [Osuna Cross-Daemon Comms](https://github.com/xpufx/osuna-cross-daemon-comms)                | Lets agents communicate with agents on another Osuna daemon through an MCP server.                                                   |
| [Osuna Antigravity ACP](https://github.com/tiezbro/osuna-agy-acp)                            | Connects Google Antigravity CLI to Osuna through ACP, with Osuna-specific context, permissions, and concurrency handling.            |
| [Desvio](https://github.com/cleiter/desvio)                                                  | Rebuilds a personal fork from a set of branches, using an agent to resolve new conflicts and Git rerere to replay known resolutions. |

## Hosting and infrastructure

| Project                                                            | What it does                                                                                         |
| ------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------- |
| [Osuna Self-hosted](https://github.com/blockfeed/osuna-selfhosted) | Packages the Osuna web UI and a local daemon as a Docker deployment.                                 |
| [Devbox Fleet](https://github.com/omrihaviv/devbox-fleet)          | Provisions and maintains per-developer GCP devboxes with Osuna, coding agents, and Tailscale access. |
