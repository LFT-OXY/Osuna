# 06 — Codex 第二层：经过中转站换号

**What to build:** 有两个以上的 Codex 号且没开「只换登录」时，Codex 的 ChatGPT 请求经过内置中转站；当前号接不了的请求在回复第一个字之前交给下一个号，开着的对话不报额度错误。用户可以打开 Switch「只换登录」让 Codex 直连 OpenAI。与「使用第三方接口」同时开着时两边都工作。用量页的请求列表写明是哪个号答的。

**Blocked by:** 04
**Status:** ready-for-agent
**Impl:** done

- [x] 接法建在 ADR 0010 上：轮换打开、开着的号多于一个、没开「只换登录」时，即使没开「使用第三方接口」也写 `openai_base_url` 指向内置中转站；关掉轮换、只剩一个号或打开「只换登录」时按 ADR 0004 / 0012 还原；「使用第三方接口」开着时这一键由两边共用，不重复写、不互相还原。关「读取 CLI 登录凭证」不改动已写的这一键。
- [x] 选号：ChatGPT 自带模型（不带「接口标识/」前缀）的请求，候选是当前号加存着的、没失效的号；先当前号，再按用户排的顺序；没有余量的排最后但不去掉。发给某个号时只换 ChatGPT 登录与 `ChatGPT-Account-Id`，其余照 Codex 原样。
- [x] 换下一个号的条件照 magpie：401、402、403、404、408、429、全部 5xx、模型下线、边缘拦截，以及文字像额度用完 / 模型不支持 / 拒绝的 400、422；对话太长不换；只在还没有任何内容发给 Codex 时换。
- [x] 号里有 credits 时，429 `usage_limit_reached` 先用同一个号再问一次（magpie `bf2e067e`）。
- [x] 粘性照 magpie 默认 auto：同一轮留在换上的号；读写过至少 1024 个缓存 token 且上次回复在 5 分钟内的对话跨轮也留着。
- [x] 所有号都不行时把最后一个上游错误原样交给 Codex。
- [x] 账本给这类请求记下答话的号与每次尝试（新字段可选）；用量页分组仍归「官方」（ADR 0014），请求列表显示「官方 · 邮箱」。
- [x] 「读取 CLI 登录凭证」关着时第二层退回只按当前号原样转发。
- [x] 「只换登录」是 Switch，保存中、保存失败照常。
- [x] 测试：daemon 端到端（假 ChatGPT 后端；扮演 Codex 发请求：429 在第一个字前交给下一个号、内容开始后不换、对话太长不换、有 credits 再问一次、粘性、所有号不行时原样报错、只换登录时不写 `openai_base_url`、与「使用第三方接口」同开时第三方模型与 ChatGPT 模型都可用、账本记下答话的号）；已有中转站判错与 CLI 配置改写套件按需加用例；app 浏览器测试（「只换登录」开关成功 / 失败、请求列表显示「官方 · 邮箱」）。
- [x] UI: Codex 提供方页 / 两个号、第二层开着 / 1280 — 「只换登录」是 Switch，说明行写明请求会经过 Osuna。
- [x] UI: 用量页请求列表 / 经过第二层的请求 / 1280 — 显示「官方 · 邮箱」。
