# 07 — Claude Code 加号与存着的号的额度

**What to build:** 用户在 Claude Code 的「账号」一节点「添加账号」，浏览器打开 Claude 的登录页，不弹终端，登录完号出现在列表里；远程设备拿到链接，把页面上显示的代码粘回来。每个存着的号有自己的私有配置目录，由真的 Claude Code 在里面续期、每 5 分钟查一次额度；失效的号显示「需要重新登录」和「重新登录」。

**Blocked by:** 02
**Status:** ready-for-agent
**Impl:** ready

- [ ] 照 magpie：在新的私有 `CLAUDE_CONFIG_DIR`（账号存储下）里后台运行真的 `claude auth login`，截下它要打开的登录地址交给客户端；主机上的桌面端直接打开浏览器，远程设备显示链接与粘贴代码的输入框，代码转给这个登录进程。完成后从该目录读出邮箱与套餐存进账号存储；没读到邮箱的拒收；已有的号更新并提示「已经有这个号」；可取消、超时可重试。「重新登录」走同一流程。
- [ ] Osuna 从不续 Claude 的 token，也从不连 Anthropic 的登录服务；续出的新 token 留在私有目录。
- [ ] 存着的号的额度：在该号的私有目录、临时工作目录里运行真的 `claude -p /usage --output-format json --tools "" --strict-mcp-config --setting-sources "" --no-session-persistence`，解析当前会话与本周的用量和重置时间；跟随每 5 分钟的检查与列表刷新。从没读到过额度的号标明「还没读到额度」。
- [ ] 登录失效（`/usage` 报未登录或凭证被拒）时标「需要重新登录」。
- [ ] 「读取 CLI 登录凭证」关着时不加号、不运行 `claude`。
- [ ] 测试：daemon 端到端（假 `claude` 程序只答 `auth login` 与 `/usage`；截下登录地址、粘贴代码、取消、超时、重复的号、没有邮箱被拒、额度解析、失效标记、总开关关时不运行）；app 浏览器测试（加号成功、失败、远程粘贴代码、重新登录）。绝不运行真的 Claude Code。
- [ ] UI: Claude Code 加号对话框 / 进行中与失败 / 1280 与 390 — 进行中有打开登录页与复制链接，远程设备有粘贴代码框；失败原因与「重试」在框里。
- [ ] UI: Claude Code 账号列表 / 两个号 / 1280 — 每个号有邮箱、套餐与窗口用量条。
