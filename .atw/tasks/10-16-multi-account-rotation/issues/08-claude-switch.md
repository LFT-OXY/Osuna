# 08 — Claude Code 换号：立即使用、移除、排序、自动规则

**What to build:** Claude Code 的号也能「立即使用」、移除、调先后，并按 05 的同一套规则自动换号与换回、设上限、固定登录到。换号后新开的 Claude Code 会话（含终端里新开的）用新号。Claude Code 开着「使用第三方接口」时轮换照常转，账号一节顶上写明订阅号此时用不上。

**Blocked by:** 05, 07
**Status:** ready-for-agent
**Impl:** ready

- [ ] 换登录：macOS 写钥匙串 `Claude Code-credentials`（提供方环境设了 `CLAUDE_CONFIG_DIR` 时加 `-<该目录 sha256 前 8 位>`），账号 `$USER`；其他系统写该配置目录下的 `.credentials.json`；同时把 `.claude.json` 的 `oauthAccount` 换成目标号的资料，只动这一键、写前重读。读写走可替换的适配器。
- [ ] 一个登录只有一个持有者：换上的号凭证移进 CLI 的默认存储、私有目录里的清掉；换下的号从默认存储收回到它的私有目录。整个过程在跨进程锁里做。
- [ ] 自动规则、上限、固定、状态标签、换号记录、移除、排序都用 04、05 做好的那一份，不另写。
- [ ] 开着的 Claude Code 进程可能在登录过期时跟着换到新号，写进开关下的说明，不另做处理。
- [ ] Claude Code 开着「使用第三方接口」时，账号一节顶上显示「Claude Code 现在走第三方接口，订阅号要等你关掉开关才用得上」，轮换照常转。
- [ ] 「读取 CLI 登录凭证」关着时不换号。
- [ ] 测试：daemon 端到端（假钥匙串与 `.credentials.json` 两种存法换号后默认存储是目标号、`oauthAccount` 已换、旧号收回、token 只在一处；98% 换走、90% 换回、固定不换、不换到没读过额度的号；总开关关着时拒绝）；app 浏览器测试（立即使用成功 / 失败、「使用第三方接口」开着时的说明行）。
- [ ] UI: Claude Code 账号列表 / 换过一次号 / 1280 与 390 — 新号「使用中」，「最近换号」有记录；390 下行菜单完整可用。
- [ ] UI: Claude Code 账号一节 / 开着「使用第三方接口」 / 1280 — 顶上有那行说明。
