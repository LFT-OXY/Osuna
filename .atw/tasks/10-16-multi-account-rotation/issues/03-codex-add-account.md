# 03 — Codex 加号与存着的号保持能用

**What to build:** 用户在 Codex 的「账号」一节点「添加账号」，浏览器打开 OpenAI 登录页，登录完号出现在列表里；不在主机前时拿到链接，在任意设备登录后把浏览器最后跳到的地址粘回来。存着的号由 Osuna 续期、每 24 小时保活，列表显示各号的额度；续期被拒或被吊销的号显示「需要重新登录」和「重新登录」。

**Blocked by:** 02
**Status:** ready-for-agent
**Impl:** done

- [x] 照 magpie 由 Osuna 跑 PKCE OAuth（Codex 的 OAuth 客户端与范围，回调监听 `127.0.0.1:1455`）；端口被占或远程设备时用粘贴的回调地址完成；10 分钟没完成算超时；可取消。拿到的登录存进账号存储。
- [x] 按 `id_token` 里的账号认重复：已有就更新这个号的登录并提示「已经有这个号」。「重新登录」走同一流程写回同一个号。
- [x] 续期（照 magpie）：要用时续、每 24 小时保活；续前在跨进程锁里重读，存的 token 已被换过就采用新的；请求发出后不中途取消；`invalid_grant`、`refresh_token_reused`、`token_revoked` 时标「需要重新登录」并退出轮换。
- [x] 存着的号的额度用现有 Codex 套餐用量来源同一处读法读（同样的请求头），用它自己的 token；跟随列表刷新与每 5 分钟的检查。（实现：每 5 分钟的检查只在这家开着轮换时读存号额度；保活总做。）
- [x] 一个登录只有一个持有者：存着的号的 token 只在 Osuna 的存储里。
- [x] 「读取 CLI 登录凭证」关着时不加号、不续期、不读额度。
- [x] 加号对话框：进行中「在浏览器里完成登录」+「打开登录页」+ 复制链接 + 取消；远程设备多一个粘贴地址的输入框；成功后关闭并高亮新号；失败、超时留在框里显示原因和「重试」。
- [x] 测试：daemon 端到端（本机假 OpenAI 登录与续期服务、假 `wham/usage`（实现：额度在 `AccountUsageReader` 接缝上用假的，另由插件单测核对存号与 CLI 登录发同样的请求头）；回调与粘贴两条路、超时、取消、重复的号、续期成功 / 被拒 / 并发不丢 token、保活、总开关关时不发请求）；app 浏览器测试（加号成功、失败、超时、远程粘贴、重新登录）。（实现：浏览器测试的超时由改写回复模拟，真实超时在 daemon 端到端里测；另加了端口被占、登录途中关总开关、CLI 拿着的号重加。）
- [x] UI: 加号对话框 / 进行中与失败 / 1280 与 390 — 进行中有打开登录页与复制链接，远程设备有粘贴框；失败时原因与「重试」在框里。
- [x] UI: 账号列表 / 一个号失效 / 1280 — 该行显示「需要重新登录」和「重新登录」按钮。
