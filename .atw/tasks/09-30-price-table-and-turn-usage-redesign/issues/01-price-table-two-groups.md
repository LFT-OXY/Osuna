# 01 — 价格表两组布局

**What to build:** 打开「价格表」页，模型分成上下两组。上面「自定义价格」组放所有无价格数据和已有自定义价格的模型（无价格数据的在前），是一张列对齐的表：四个价格列用等宽、带 `$` 前缀、数字右对齐的输入框，和表头、只读数值对齐到同一条线；模型名下面一行固定高度的状态行（无价格数据 / 自定义价格），出错时错误文字替换这一行、空格子标危险色边框，不推动下面的行；无价格数据的行叠一层很淡的琥珀底；组标题带数量，有无价格数据的模型时右侧有「无价格数据 N」徽标；组为空时显示「所有模型都有价格」。已自定义的行只读显示数值，用铅笔图标进入编辑（保存 / 取消），行为与现在的编辑相同。下面「LiteLLM 价格」组默认折叠成一行「N 个模型由 LiteLLM 定价」，点开是只读表（四列与上面同一套列宽，0 用淡色）；自动更新开关和「立即刷新」挪到这一组标题右侧，副标题按价格表来源区分「LiteLLM 快照」与「联网更新」，再接多久前更新和单位；控件失败的原因显示在这一组里。紧凑布局（<720）不再横向滚动：模型名与状态一行、四个输入框一行、操作在下；LiteLLM 行把四个价格压成一行小字；自动更新与刷新移到页面底部单独一张卡片。加载中、不可用、需要更新主机、出错可重试、没用过任何模型这些页面级状态照旧，在两组的位置显示一次。设计见 PRD 的 Implementation Decisions 与原型画面 A1、A4、AM。
