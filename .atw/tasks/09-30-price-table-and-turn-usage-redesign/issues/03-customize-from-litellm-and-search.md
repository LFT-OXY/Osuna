# 03 — 从 LiteLLM 行自定义与搜索

**What to build:** 展开「LiteLLM 价格」组后，顶部有一个搜索框，按模型 id 做不区分大小写、去首尾空格的子串过滤，只作用于这一组；没有结果时显示「没有名称包含 X 的模型」。每一行在桌面上悬停时出现「自定义」（ghost xs 按钮，按 docs/hover.md 的悬停模式），紧凑布局和原生端常显。点了之后这个模型立刻出现在「自定义价格」组、以当前 LiteLLM 价格预填进入编辑，状态行写「LiteLLM 价格」，不在 LiteLLM 组里重复出现；「取消」让它回到 LiteLLM 组，什么也不写；「保存」写入自定义价格，之后它作为自定义价格留在上面一组。搜索词与这组「正在自定义」的模型只存在组件状态里，离开页面重置。设计见原型画面 A2。
