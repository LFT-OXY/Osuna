# 04 — 本轮用量面板重设计

**What to build:** 对话流里一轮结束后，悬停 footer 的用量段（紧凑布局点按）弹出的「本轮用量」面板改成「总览 + 明细」：固定宽 300，内容完整落在边框内、对准用量段、夹紧在窗口内 8px。自上而下：头部「本轮用量」与时钟图标加耗时；估算成本大字，后接「估算成本」，本轮有模型无价格数据时带点状下划线；统计格依次为输入、缓存、输出，推理 > 0 时加「其中推理」，推理不再拼进输出数字；只用一个模型时一行「模型 <id>」，多个模型时「按模型」列出每个模型两行（名称与成本 / 输入·缓存·输出与推理小字），无价格数据的模型成本位写「无价格数据」；底部脚注「估算成本 · 按公开 API 价格计算」，有模型无价格数据时上方加一行提示它按 $0 计入、可在「设置 › 价格表」自定义。模型名单行省略，不撑宽面板。面板外框通过 TooltipContent 的参数与样式定宽、去掉默认内边距、圆角 10，Tooltip 组件的默认值与其他调用方不变；触发方式、footer 那段文字与骨架条不变。设计见原型画面 U1、U2、U3、UM，歪斜根因见 research/baseline-dom.md。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

**Impl:** done
