# 03 — 接口顺序：拖动、菜单与键盘排序

**What to build:** 用户能排接口的先后，这个顺序决定自动切换先去哪家、只写模型名时归哪家。

- 新 RPC 整体改写顺序；存储里接口数组的顺序就是接口顺序；新建排在最后。
- 中转站选路、裸模型名归属、默认模型的自动挑选、「已开启 / 已关闭」两组的排列都按这个顺序。接口在两组之间移动时保留位置。
- 列表页：桌面端拖动；行菜单「上移 / 下移 / 移到最前 / 移到最后」；选中行后 Alt+↑ / Alt+↓。
