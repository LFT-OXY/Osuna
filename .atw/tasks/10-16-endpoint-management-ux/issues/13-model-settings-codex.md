# 13 — 模型设置窗口与写进 Codex

**What to build:** 每个模型的资料能手改，并影响 Codex。

- 接口新字段 `modelSettings`（按模型 id + 整家默认）。本张做：显示名（可「恢复默认」）、上下文、回复上限、思考档位（多选，一档不勾就不发思考参数）、能看图、压缩阈值（token 数）；整家默认里的上下文、回复上限、压缩阈值。上游模型名与只用这种格式归 15 号。
- 取值顺序：单个模型 → 整家默认 → 上游清单 → models.dev → 内置默认；models.dev 补显示名；撞名时选单显示模型 id。
- 模型行菜单打开「模型设置」窗口；窗口里写明 Claude Code 没有显示名与看图的设置、Codex 没有回复上限的设置。
- 写给 Codex 的模型清单按模型写显示名、思考档位、`input_modalities`、上下文；有压缩阈值时上下文取二者较小（照 magpie `codexcat`）。
- 改完按子任务 2 已有的规则提示哪些会话要重开。
