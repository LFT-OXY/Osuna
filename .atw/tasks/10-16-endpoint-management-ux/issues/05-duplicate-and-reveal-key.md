# 05 — 复制一家与读回 key

**What to build:** 同一中转服务的第二把 key 不用从头填；保存过的 key 能读回原文。

- 接口菜单「复制」：打开预填好的添加窗口，内容是这家的全部（地址、已选模型、档位映射、联网搜索开关，以及以后工单加的设置），名字「原名 副本」（英文 "<name> copy"）；key 框留空并提示「沿用原来的 key」，保存时 daemon 从原来那家拷 key；保存了才算数。
- 名称冲突加「 2」「 3」……，标识冲突加 `-2`……，避让在 daemon 做（「再加一家」以后也用它）。
- 编辑窗口 key 框旁「显示」：新 RPC 按接口 id 返回 key 原文，没有确认、不限次数（照 magpie）。
