# 15 — settings.json 带 BOM、带注释也照改

**What to build:** `settings.json` 开头带 BOM，或写了注释、尾随逗号时，「使用第三方接口」照常能打开，BOM、注释和排版原样保留；带注释时提醒用户 Claude Code 自己读不了这份文件。

- **读**：开头的 BOM 去掉；注释、尾随逗号照样认（JSONC）。
- **写**：只动负责的键，注释与排版原样；有 BOM 的写回时保留。读写 JSONC 用项目里已有的库，不新加依赖。
- **带注释或尾随逗号时**：照改，并在提示区显示「设置文件带注释」：Claude Code 读不了这份文件，终端会弹错，Osuna 里的 Claude 对话会直接走官方；删掉注释后恢复；带「如何修复」。
- **连 JSONC 都读不懂的**：照旧拒绝，原因用用户的界面语言说明。
- **先核实推断**（读 Claude Code 源码与文档，不在本机运行 Claude Code）：Osuna 用 SDK 开的 Claude 对话遇到读不了的设置文件，是否整份跳过、直接走官方。提示文字按核实结果写。
