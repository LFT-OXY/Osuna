# 19 — 打开开关时怎么挑默认模型；默认模型可指定某一家

**What to build:** 打开「使用第三方接口」时，只要有接口提供 CLI 当前在用的模型就沿用它，并在设置页说明这次是怎么挑的；默认模型也可以指定某一家接口的模型。

- **挑法**：照 magpie 依次取——已有且还能用的保持（kept）；上次关掉前用的放回（again）；CLI 当前在用、有接口提供的沿用（same）；档位名指向的映射模型（alike）；都没有时取第一个（first）。用 ChatGPT 登录的 Codex 保持它自己上次选的模型、接口模型并进 `/model`（joined，09 号工单写配置）。
- 结果告诉 app 这次是哪一种，设置页显示一句说明（如「经中转站继续用它原来的模型 X」）；没有能用的模型时照旧拒绝并说明。「上次关掉前用的」记在接管记录里。
- **指定某一家**：默认模型可以是光秃秃的模型名，也可以是「接口标识/模型名」（先用那家，不行再按中转站现有规则换到提供同名模型的别家）。设置页的选项同时列出两种，指定某家的显示成「模型名（接口名）」。写给 Codex 的模型清单里要有这个名字，免得 Codex 当成不认识的模型。
