# 14 — 多选批量挪；续不上时报错里给挪动按钮

**What to build:** 整理很多旧对话时不用一条条挪；续对话失败时当场就能修好。

- **多选**：会话历史新加多选模式。选中几行 Codex 对话后，一起挪到另一个 Codex 服务商（13 号工单的对话框与 RPC）；结果逐条说明：挪了，或跳过及原因。
- **续不上**：续对话因为它的 Codex 服务商已不在 Codex 设置里而失败时（``Model provider `…` not found``），错误显示用户界面语言的说明，并给出「挪到另一个 Codex 服务商」按钮，打开同一个对话框。错误要带可识别的原因（代码），app 不靠匹配英文原文判断。
