# 25 — 「被绕过」提示

**What to build:** 设置没问题，但 CLI 最近用过、请求却没到中转站时（例如旧进程还在用旧设置，或配置之外的东西盖过了它），提示区报「被绕过」，按钮「重新应用」「切回官方」。只在读状态时检测，不在后台监视文件。

- 中转站记下每个提供方最近一次收到请求的时间（02 号工单已能认出是哪个 Agent）。
- CLI 自己的会话记录：Claude Code、Codex 各自会话文件的最后写入时间，具体看哪些文件对照 magpie 定；经可替换的入口读，测试用临时目录。
- 最近一次改写之后，会话记录有新写入、中转站却没收到这个提供方的请求，才算被绕过；改写之前的写入不算。
- 「重新应用」后，之前的使用不再算。
