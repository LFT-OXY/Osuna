# 26 — 关开关前预览会改回什么

**What to build:** 关「使用第三方接口」之前，确认框逐条列出会改回、删除、新建的设置，用户确认后才改，可以放心关掉。

- **新 RPC**：在当前文件内容上算出关掉以后的结果，不写盘。按文件列出改回的项（现在的值、改回的值）、删掉的项、新建或删除的文件；Codex 另说明 Osuna 的 Codex 服务商会保留、用它开过的对话还能打开。
- 用和真正关掉同一套还原逻辑来算，这样以后新加的负责的键自动出现在预览里。
- **确认框**：标题「关闭 {提供方} 的第三方接口？」一类；读取中显示「正在读取要改回的地方…」；长列表折叠成「还有 N 行」；算不出时（例如文件读不懂）改用文字说明，仍可确认；取消与确认。
