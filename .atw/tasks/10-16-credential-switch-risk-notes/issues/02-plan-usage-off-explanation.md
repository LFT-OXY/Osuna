# 02 — 套餐用量界面的「已关闭」说明

**What to build:** 开关关着时，用户在套餐用量弹窗和用量页的套餐用量一节看到「已关闭读取 CLI 登录凭证，套餐用量不显示」和次要按钮「打开设置」，点了跳到主机设置页的「隐私」一节；侧边栏的套餐用量摘要、输入框下的上下文条、Agent 的上下文详情直接不显示套餐用量，不放说明。钉住的窗口在关着期间保存着，开回来就回来。

**Blocked by:** 01
**Status:** ready-for-agent
**Impl:** ready

- [ ] 客户端据 `usage.list_reports` 响应里的「已关闭」字段判断，不另发请求；没有这个字段时照现在的空状态。
- [ ] 弹窗与用量页显示说明行和「打开设置」（次要按钮样式，不是蓝色链接）；跳转落在「隐私」一节。
- [ ] 侧边栏摘要、上下文条、上下文详情关着时不显示套餐用量；设备上钉住的窗口不被清掉，开回来后照原样显示。
- [ ] 9 种语言，中文是真翻译。
- [ ] 测试：app 浏览器测试（关后弹窗与用量页的说明行与跳转、侧边栏摘要消失、开回来后钉住的窗口恢复）。
- [ ] UI: 套餐用量弹窗、用量页 / 开关关着 / 1280 与 390 — 显示说明行与「打开设置」按钮，按钮不是蓝色链接样式；侧边栏底部没有套餐用量摘要。
