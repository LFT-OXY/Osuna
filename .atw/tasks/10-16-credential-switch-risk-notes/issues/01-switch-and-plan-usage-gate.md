# 01 — 「隐私」一节与开关：关掉后不读任何套餐用量

**What to build:** 主机设置页多一节「隐私」，里面有 Switch「读取 CLI 登录凭证」，默认开，下面是开关说明。关掉后，daemon 不让任何套餐用量来源（内置的、安装的）运行，切到关的那一刻丢掉内存里已经读到的账号与报告，「用掉一次重置」被拒；新旧两个套餐用量 RPC 都返回空。开回来后不重启就能重新读到。本工单不做「已关闭」说明行（02）、关前确认框（03）、环境变量（04）、Codex 与导入（05）。

**Blocked by:** None — can start immediately
**Status:** ready-for-agent
**Impl:** done

- [ ] daemon 内只有一处回答「现在能不能读 CLI 登录」，后续工单的闸门都问它（04 的环境变量也在这里合进去）。
