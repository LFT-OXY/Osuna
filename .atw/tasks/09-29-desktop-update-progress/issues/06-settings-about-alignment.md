# 06 — 设置 → 关于对齐新流程

**What to build:**

设置 → 关于的应用更新那一行改为和侧栏卡片使用同一套阶段：

- 状态文字按阶段显示：下载中显示百分比（例如「正在下载 42%」），已下载时附重启风险提示。
- 主按钮随阶段变化：发现更新时是「更新」，点了开始下载；下载中禁用；已下载时是「安装并重启」，点了直接安装；安装中禁用。「检查」按钮保持不变；失败时继续显示「前往 Releases 手动下载」。
- 去掉安装前的系统确认框。
- 在设置里手动检查发现新版本、或在设置里发起下载，都会解除侧栏卡片的本次运行隐藏，离开设置页后侧栏卡片显示当前阶段。
- 清理已经没有调用方的旧文案 key（包括原来确认框的文案）。

**Blocked by:** 03 — 下载进度
**Status:** ready-for-agent
**Impl:** ready

- [ ] 设置页显示的阶段和侧栏卡片一致，下载中显示百分比。
- [ ] 在设置里点「更新」开始下载，离开设置页后侧栏卡片显示同一份进度。
- [ ] 已下载时点「安装并重启」直接安装，不弹系统确认框。
- [ ] 之前点过「稍后」的用户在设置里手动检查发现新版本后，侧栏卡片重新出现。
- [ ] 9 种语言里没有残留的无用更新文案 key。
- [ ] 状态机测试覆盖「从设置页发起的检查和下载会解除隐藏」。
- [ ] `npm run typecheck`、`npm run lint` 通过。
