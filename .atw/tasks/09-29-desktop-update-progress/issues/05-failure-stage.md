# 05 — 失败阶段

**What to build:**

区分下载失败和安装失败。卡片的失败阶段显示错误信息，按钮是「重试 / **前往 Releases 手动下载**」，× 只在本次运行期间隐藏。「重试」重新执行失败的那个动作：下载失败就重新下载，安装失败就重新安装。进入失败阶段时解除本次运行的隐藏，保证错误能被看到。

静默自动检查失败仍然只记录日志，不打扰用户。

**Blocked by:** 02 — 手动下载主链路
**Status:** ready-for-agent
**Impl:** ready

- [ ] 下载失败时卡片进入失败阶段并显示错误信息；点「重试」重新开始下载。
- [ ] 安装交接失败（包括超时）时卡片进入失败阶段；点「重试」重新安装；「前往 Releases 手动下载」打开发布页。
- [ ] 之前被隐藏的卡片在进入失败阶段时重新出现。
- [ ] 静默自动检查失败不出现卡片。
- [ ] 更新服务测试覆盖下载失败写入快照；状态机和描述器测试覆盖两种失败的按钮、重试走向和解除隐藏。
- [ ] 新文案补齐 9 种语言；`npm run typecheck`、`npm run lint` 通过。
