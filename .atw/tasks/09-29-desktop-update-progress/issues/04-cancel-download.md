# 04 — 取消下载与切换通道

**What to build:**

下载中的卡片出现「取消」按钮。点了之后，更新服务用 electron-updater 的取消令牌中止下载，阶段回到「发现更新」；取消不算错误，不进入失败阶段。

下载中切换发布通道（正式版/Beta）时，更新服务先取消当前下载，再清空更新状态，然后按新通道重新检查。

**Blocked by:** 02 — 手动下载主链路
**Status:** ready-for-agent
**Impl:** ready

- [ ] 下载中点「取消」会中止下载，卡片回到「发现更新」，没有错误提示；之后可以再点「更新」重新下载。
- [ ] 下载中切换发布通道会取消下载，回到「发现更新」；新通道没有更新时显示已是最新。
- [ ] 更新服务测试覆盖：取消后阶段回到发现更新且不报错；切换通道会取消下载并清空状态。描述器测试覆盖下载中阶段的「取消」按钮。
- [ ] 新文案补齐 9 种语言；`npm run typecheck`、`npm run lint` 通过。
