# 01 — 更新状态机改为每窗口单例

**What to build:**

预重构。现在每个调用应用更新 hook 的组件都会各自创建一个状态机，侧栏更新卡片和设置 → 关于各持一份状态，可能互相不同步。改成每个窗口的渲染进程只有一个状态机实例，所有调用方共用；用户可见的行为不变。

- 启动时的静默检查和每 30 分钟一次的自动检查只跑一份，不因为多一个调用方就多跑一次。
- 发布通道变化时，共用的实例用新通道检查。

**Blocked by:** None — can start immediately
**Status:** ready-for-agent
**Impl:** done
