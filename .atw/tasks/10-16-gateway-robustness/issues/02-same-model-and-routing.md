# 02 — 同一个模型与选路

**What to build:** 只差写法的模型名算同一个模型，规则照 magpie 的同名判断：
- 去掉厂商前缀；
- 版本号里的点、下划线改成连字符，包括 Fireworks 写法里的 `p`；
- 去掉快照日期。

效果：CLI 请求的名字能对上接口列出的另一种写法；换家时，写法不同的同名模型互相做后备；发给每家的仍是它自己列出的写法。

其他规则：
- 「接口标识/模型」先当作指定某家；斜杠前面不是任何一家的接口标识时，才当厂商前缀去归一。
- 请求里的 `~` 当作 `/`。
- 找不到模型时，404 说明原因，并给出最接近的三个 id。
- Codex 整理记忆和 auto-review 的请求（模型名是 `codex-auto-review`，或带 `x-openai-subagent: guardian` 头）没有对应模型时，发给这段对话上一轮用的模型。
