# 09 — 判错与冷却

**What to build:** 照 magpie 补齐判错和冷却的规则：

- **402**：只有说的是用量上限、又没提钱时，才算额度用完，可以只冷却这个模型；其他 402 仍算欠费。
- **恢复时间**：多认两种写法：「resets in 0h 19min」这种文字，以及智谱 1308、1310 不带时区的时间（按北京时间算）。
- **也算值得换家**：被厂商防火墙挡住的请求；不说原因的 400（包括 Command Code 的）。
- **Cline 免费模型额度用完**：只冷却这个模型。
- **失败次数**：模型自己的失败次数和整家分开计，模型级冷却按模型自己的次数翻倍。
- **原地重试**：后面剩下的候选都因额度在冷却时，把当前这家当最后一家，原地重试。
- **全部在冷却时的提示**：恢复时间带上时区；复述排第一那家的原话。

智谱包在 200 里的拒绝归第 18 张，因为要读 2xx 回复的内容。
