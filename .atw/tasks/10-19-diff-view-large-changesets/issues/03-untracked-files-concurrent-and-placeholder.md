# 03 — 新建文件多时也快，超过 2MB 不再消失

**What to build:** 改动里有很多未跟踪的新建文件时，daemon 不再一个一个串行处理，Changes 面板出来得更快。patch 总量超过 2MB 以后的新建文件不再从列表里消失，而是和已跟踪文件超限时一样，显示「太大」占位。

- 未跟踪文件改为有上限的并发处理，走现有的 git 子进程限流，不另开池。结果仍按原来的顺序拼接，输出确定。
- 超过总量上限后的未跟踪文件输出 `status: "too_large"` 的占位，不加新的 status 值。
