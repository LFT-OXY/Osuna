# 09 — 窗口最小化时暂停接收

**What to build:** 桌面版窗口最小化（页面进入 hidden 状态）时，客户端释放 diff 订阅，daemon 不再为它计算、推送；窗口恢复时重新订阅，马上拿到一次最新快照。

- 和现有的「tab 不活跃就退订」走同一条路径，不另起机制。
- Web 版切到别的浏览器标签、页面 hidden 时同样生效；原生端应用进后台时行为相同，不做实机验收。

**Blocked by:** 02
**Status:** ready-for-agent
**Impl:** ready

- [ ] 客户端用例：页面变 hidden 后订阅被释放；变回 visible 后重新订阅，并收到最新快照。
- [ ] 用例：hidden 期间发生的改动，恢复后显示的是最新内容，不是 hidden 之前的旧内容。
- [ ] 桌面版实测：最小化期间模拟 Agent 持续改文件，daemon 日志里没有为这个订阅做的刷新；恢复后面板 2 秒内显示最新内容。
