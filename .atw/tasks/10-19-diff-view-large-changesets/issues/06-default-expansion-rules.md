# 06 — 默认展开规则

**What to build:** Changes 面板按规则决定每个文件默认展开还是收起，用户的手动选择优先，已经显示过的文件不会突然变。

规则作为一个纯函数，按以下顺序判断：
1. 用户手动展开或收起过，按用户的；
2. Generated file，收起（本工单先留好入口，07 接上识别）；
3. additions + deletions > 1000，收起；
4. 本 tab 第一次看到这个文件时，改动文件总数 ≤ 10，展开；
5. 总数 > 10 时，按面板里的显示顺序，前 3 个展开，其余收起。

- 默认状态只在本 tab 第一次见到这个文件时决定。所以 Changes 的 tab 状态要扩展，同时记下用户主动展开过的文件，不只记收起的；持久化 schema 是 strictObject，新字段设为可选。
- 「全部展开」清空所有收起，包括 Generated file 和大文件；「全部收起」不变。
- 大文件在文件头加灰色标签「改动 1,234 行」/ "1,234 lines changed"（数字带千分位），样式参照文件头里现有的增删行数，走 i18n（所有已支持语言都补齐）。因为文件多而收起的普通文件不加标签。
- Web 与原生共用规则；原生端不做实机验收。
