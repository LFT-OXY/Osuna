# 03 — 栈式布局（窄桌面与手机）

**What to build:** 内容区放不下两列，或者处于紧凑判定（手机）时，Providers 页改成「列表 → 推入详情」。

- 列表行在开关后面带 ›，点行用 push 进入子路由，显示全屏详情。
- 返回回到列表。窄桌面的页头是「Providers / {名称}」面包屑，点「Providers」回到列表。
- 手机的 BackHeader 标题是提供方名称，右侧放仅图标的「刷新」；⋯ 的位置先留好，菜单由 05 实现。页内头部块只保留图标、名称、徽章和模型数。
- 地址里的提供方不存在时回到列表。
