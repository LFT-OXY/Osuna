# 02 — 宽屏列表 + 详情与子路由

**What to build:** 桌面端宽窗口下，设置 → 主机 → Providers 变成页内「左列表、右详情」。

- 进入页面默认选中第一个提供方，地址指向它的子路由「Providers / {provider}」。
- 点列表行切换右侧详情和地址，用 replace，返回键不会逐个回退选中项。
- 直接打开某个提供方的子路由会选中它；地址里的提供方不存在时回到第一个。
- 列表行只有图标、名称、状态行和开关，状态行按 prd 的规则表显示；点开关不改变选中项。选中行用 surface2 高亮。
- 右侧用 01 的详情组件，加页面外框的头部：40 的图标框、名称、状态徽章、「{N} 个 Model」、secondary「刷新」。
- 两列容器按 prd 的尺寸排（列表 280、间距 24、详情最大 720、整体最大 1056 居中，列表 sticky）。

这一张不处理栈式布局，交给 03；「添加 Provider」那一节暂时留在列表下面，由 04 移除；行里的错误原文、⋯ 和「如何安装」由 05 清理。

动手前先读 `docs/expo-router.md`：子路由必须是和主机分区路由并列的独立路由名，照搬项目详情的做法。
