# 04 — 子图节点与面包屑导航

**What to build:** 在逻辑图面板里点一个 **Subgraph node**，画布换成它的下一层，顶部出现面包屑（Breadcrumb）路径，例如"用户登录 › 密码登录"，最后一级是当前层；点前面任一级回到那一层。切换图名或图被 Agent 改动后，如果当前层已不存在，回到最顶层。排版纯函数按层输出，只排当前层的节点。见 PRD User Story 33 与 `ui-direction.md`。
