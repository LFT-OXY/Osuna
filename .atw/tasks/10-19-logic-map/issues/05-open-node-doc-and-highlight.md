# 05 — 点节点打开节点文档，图上高亮

**What to build:** 在逻辑图面板里点一个 **Node**，通过现有的"打开文件"入口在主区域开一个文件标签显示它的 **Node doc**，逻辑图留在右边栏。指向外部文档的节点，打开那份文档并定位到对应段落：用存下的标题文字在打开时换算成起始行号。主区域当前聚焦的文件标签如果是某个节点的文档，这个节点在图上用蓝色描边高亮。还没指向正式文档的节点（自有文档是临时要点、带"还没指向正式文档"标记）在卡片下方显示浅黄底的"未指向文档"小标签。PRD 留了一项未核实：Markdown 文件在渲染预览模式下能否滚动到指定行；先核实，不能的话本票给文件预览补上这个能力。见 PRD User Stories 34–36、23 与 `ui-direction.md`。
