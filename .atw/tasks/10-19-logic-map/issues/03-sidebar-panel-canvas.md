# 03 — 右边栏显示逻辑图（Dify / Coze 样式）

**What to build:** 新增"逻辑图"面板，注册到面板注册表，只允许放在 Explorer sidebar，并且是单例。它不是每个 workspace 一出生就带的默认标签：某个对话第一次打开开关时自动加入并选中，也可以从右边栏的 + 菜单打开。面板顶部是图名下拉框（切换这个 workspace 的各张图，默认显示当前对话维护的那张）和节点数；主体是复用现有可缩放视图组件的画布，可以拖动、缩放。Agent 更新图后不用手动刷新就显示新版本。排版是一个纯函数：输入骨架，输出坐标，从上往下排，用层级布局库（候选 `@dagrejs/dagre`，本票确认并新增依赖）。画法照 `ui-direction.md`：灰底点阵画布；白卡片加柔和阴影；每种节点一个彩色圆角图标块（开始 / 结束蓝、判断青、步骤紫蓝、失败步骤红、子图橙）；判断卡片里一行一个分支（"如果 / 否则如果 / 否则"加灰底条件），出口圆点在行尾；正常连线靛紫色带箭头，通往失败步骤的线红色；选中蓝色描边。鼠标停在卡片上显示完整标题。各种状态都有画面：这个 workspace 还没有逻辑图时显示怎么开启；加载中；新建后 Agent 还没写入的空图；图文件损坏时提示哪张图、哪个文件出了什么问题；主机版本太旧时提示更新。本票只画当前这一层；子图节点画成带"子图 · N 个节点"标签的卡片，点进去在 04 做；点节点打开文档在 05 做。原型画面：任务目录 `prototype/direction-d.html`、`prototype/shot-d.png`。
