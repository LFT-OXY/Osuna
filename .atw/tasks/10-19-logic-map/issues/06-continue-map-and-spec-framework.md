# 06 — 接着已有的图继续，配合项目自带的 spec 框架

**What to build:** 打开输入框的"逻辑图"开关时，弹出选择层：新建一张，或从这个 workspace 已有的图里挑一张接着画（用 02 的列出 RPC）。草稿对话和运行中的对话都能用；隔天开新对话也能接着补同一张图。说明块补齐 spec 框架相关的指示：第一次为一张图开工时，先判断项目有没有 spec 框架（自带需求文档体系，比如 ATW），把判断记进图里（02 的"记录 spec 框架判断"操作），并在回复里告诉用户这个判断和节点文档会指向哪里；用户在对话里纠正时改正并重新记录。有 spec 框架的项目，节点只写 3 到 6 句临时要点（这一步做什么、有哪些规则、走哪条分支）并带"还没指向正式文档"标记；框架写出正式文档后，Agent 把节点改成指向对应段落。接着某张图重新打开开关时，说明块要求 Agent 先把带标记的节点补上指向，再继续聊。没有 spec 框架的项目，每个节点写完整的节点文档。见 PRD User Stories 3、15、16、19–24 与 ADR 0013。
