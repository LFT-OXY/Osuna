# 02 — 窄栏空间不足时的取舍

**What to build:** 输入框变窄（分屏、小窗口）或分支名很长时，窄栏按固定顺序让位：分支名至少保留约 80px，并在剩余空间内截断；仍放不下时，先从末尾隐藏窗口段，再隐藏套餐名段，第一个窗口段始终保留。规格见 `prd.md` 中「宽度取舍是一个纯函数」一条，以及决策 Q17。

**Blocked by:** 01
**Status:** ready-for-agent
**Impl:** ready

- [ ] 单元测试覆盖：全部放得下；隐藏一个末尾窗口段；隐藏全部后续窗口段；再隐藏套餐名段；极窄时仍保留第一个窗口段
