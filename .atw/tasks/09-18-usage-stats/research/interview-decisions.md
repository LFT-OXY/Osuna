## 未单独提问、按默认处理的假设

- 无数据保留期，不自动删除（同参考项目）。
- 价格表自动更新开关放在「用量」页价格表区块，属 daemon 配置（`config.json`）。
- 未知模型记 $0 并标"无价格数据"；UI 一律写"估算成本"。
- 来源显示名：Claude Code / Codex / Pi · <后端> / OMP · <后端>，后端名首字母大写，少数特例（OpenAI、GitHub、xAI）走固定表。
- 存储行粒度最初假设为 (usage source, model, sessionId, cwd, UTC 小时桶) + 估算成本落盘；已被 07 号票取代：UTC 15 分钟桶、成本不落盘、`cli` + `backend` 两列，见 `map-issues/07-storage-and-aggregation.md`。
- Q10 的「Composer 工具条用量条」已被 13 号票修订：每轮 token / 成本在 turn footer，会话合计在环形表弹层，环形表旁加 `已用 / 上限` 文字，见 `map-issues/13-composer-usage-strip-prototype.md`。
