## Answer

四轮原型（2026-10-14）。界面细节全部在 `ui-direction.md`；原型产物在 `prototypes/08-ui/`（第一轮，否决）与 `prototypes/08-ui-r2/`（定稿）。逐轮问答见 `research/decisions.md`「08 票」节。

### 推翻与修订的旧决定

- **Q7 作废**：不再塞进 Agent 的设置页，设置里**新开「第三方接口」页**（主机级）管理所有接口（U1）。
- **Q17 小横条作废**：composer 上方不加「当前实际在用」横条。
- **04 票 D3 作废**：不再「每个 Agent 对每家接口各一个开关」；改为**每个 Agent 一个总开关「使用第三方接口」**，打开即可用所有开着的接口的已选模型；**每家接口自带一个全局开关**，原 D7「暂停」并入它，状态叫「已关闭」（U2）。
- **04 票「每家一个协议」修订**：一家接口**一把 key，最多三个格式地址**（Anthropic / OpenAI Chat / OpenAI Responses，至少一个），配「自动检测」（U5）。
- Q18「暂停」→ 接口开关；「立刻恢复」保留。状态词改为 可用 / 冷却中 / 需要检查 / 已关闭。

### 界面（定稿，详见 `ui-direction.md`）

1. 侧栏「提供方」下方新增「第三方接口」列表页，照「提供方」列表页分「已开启 / 已关闭」两组，每行带格式、主机名、已选数、冷却 / 需要检查状态与接口开关。
2. 添加弹窗只填连接：名称、key、地址 +「自动检测」、三种格式地址；保存后进详情页拉模型。
3. 详情页：连接区（三格式地址 + key）、模型区（**左栏家族目录 + 右栏当前家族的模型，每行小开关，不用勾选**；默认全关；家族按模型名前缀识别，厂商图标借 magpie）、Claude 档位映射区。
4. Claude Code / Codex 页只剩：总开关、默认模型、「管理第三方接口 ›」入口。
5. 聊天模型选择器按接口名分组、模型名前加家族小图标（文字定，未画）。
6. 删除接口用 `confirmDialog` 写明对各 Agent 默认模型的影响。

### 数据模型修订（替换 04 票 Answer 的对应条目）

- **接口**：去掉单值 `baseUrl` / `protocol`，改为三个可选格式地址（`anthropic_messages` / `openai_chat` / `openai_responses`，至少一个）；`paused` 改为接口开关（关 = 所有 Agent 不用、持久保存）；`slug`、`name`、key、`models`、`modelMapping`、创建顺序照 04。
- **每个 Agent**：`{ 使用第三方接口: boolean, defaultModelId }`，取代 `enabledEndpointIds`。总开关关 = 官方，CLI 配置按现有逻辑还原，口令作废（05）。总开关只在至少一家接口开着时允许打开。
- **路由**：04 票三条规则里的「这个 Agent 开着的接口」一律读作「开着的接口」；「对该 Agent 未打开」改为「已关闭」。
- **每次请求挑格式**（照 magpie，见 decisions.md U5）：这家有 Agent 自己格式的地址就直通；Claude 模型且有 Anthropic 地址时一律走 Anthropic；否则翻译到第一个可用格式（Claude 模型 Anthropic 优先，其余 Chat → Responses → Anthropic）。被拒后换格式重发不做（06）。
- **RPC**：`fetch_models` / `test_connection` 改为按「地址 + 格式」；新增一条「自动检测」请求（三种格式各发最小测试请求，回各自结果与建议地址）；04 票的「设置开关与默认模型」请求改为「设置总开关与默认模型」，「暂停 / 恢复」请求改为「接口开关 + 立刻恢复冷却」。
- **迁移**（替我定的，见下）：旧接口的 `baseUrl` 按旧 `provider` 填进对应格式地址（claude → Anthropic，codex → OpenAI Responses）；某 Agent 当前启用的接口 → 开着，该 Agent 总开关打开、默认模型取那家旧的默认模型；其余旧接口 → 已关闭，保持迁移前「只是存着」的行为。
- **老 App 投影修订**：`activeEndpointId` = 总开关开时持有默认模型的开着接口中最早一家，关时 null；`set_active(id)` = 打开总开关、确保该接口开着、默认模型取它的第一个已选模型（当前默认它也有则保留），**不关其它接口**（否则会影响另一个 Agent）；`set_active(null)` = 关总开关；老 `save` 的 `baseUrl` 按 provider 填进对应格式地址；老 `list` 的 `baseUrl` 取该 Agent 自己格式的地址，没有就取第一个。

### 替用户定的（已在对话中说明）

- 页面名沿用「第三方接口」，不叫「中转站」（可能放官方 API）。
- 添加分两步（弹窗填连接 → 详情页拉模型），不在弹窗里挑模型。
- 迁移时未启用的旧接口记为「已关闭」；老 App `set_active` 不关别的接口。
- 不做预设中转站清单、按 Agent 精简模型、按模型指定格式。
- 状态词「可用」替代「使用中」。

### 对其它票的影响

- **04**：见上「数据模型修订」，已在 04 票末尾加修订指针。
- **05**：socket 监听时禁用的是「使用第三方接口」总开关；口令在总开关从关到开时生成、关时作废；`model_catalog_json` 在接口开关 / 已选模型 / 总开关变化时重新生成。
- **06**：直通的条件改为「这家有 Agent 自己格式的地址」，Claude 模型例外走 Anthropic。
- **07**：「对该 Agent 的开关已关」读作「接口已关闭」；「开关全关」读作「总开关关」；套餐用量提示在总开关打开时显示。
