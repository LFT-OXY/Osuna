# 界面说明：第三方接口（08 票定稿）

桌面端（Electron / Web）界面。官方 Paseo 手机 App 不改，只靠老客户端投影照常可用（04、07 票）。视觉完全沿用 Osuna 现有设置页设计系统（`docs/design.md`、`docs/forms.md`、`docs/menus.md`），不引入新风格；本说明只定结构、控件与状态。

原型与截图（一次性，不进正式代码）：

- 定稿四画面：`prototypes/08-ui-r2/style-explorer.html`（`list` / `form` / `detail` / `agent`，含现状基线）。
- 模型列表定稿：`prototypes/08-ui-r2/models-d.png`；比较过的三种见 `prototypes/08-ui-r2/models-explorer.html`。
- 第一轮被否决的 A/B/C：`prototypes/08-ui/style-explorer.html`。
- 生成脚本：`prototypes/08-ui-r2/scripts/`（在真实设置页 DOM 上替换区块后存成离线 HTML）。

## 用户任务

1. 把手上的几家中转站（地址 + key）录进来，拉取它们的上游模型，挑出要用的。
2. 让 Claude Code / Codex 用上这些模型，并设一个默认模型。
3. 随时看哪家在冷却、哪家 key 坏了，必要时关掉某家或立刻恢复。

## 信息结构（magpie 式三层）

```
设置 › 主机 › 第三方接口（新页，整台主机共用）
  ├─ 列表：每家一行 + 接口开关
  ├─ 添加 / 编辑连接（弹窗）
  └─ 接口详情：连接 · 模型（按家族挑选）· Claude 档位映射
设置 › 主机 › 提供方 › Claude Code / Codex
  └─ 「第三方接口」区：使用第三方接口（总开关）· 默认模型 · 管理第三方接口 ›
聊天 › 模型选择器：Claude Code / Codex 下按接口名分组
```

## 画面

### 1. 第三方接口列表页

- 侧栏「主机」组里「提供方」正下方新增「第三方接口」，图标用插头（lucide `plug`，实现时可换）。
- 版式照「提供方」列表页（`screens/settings/providers-section.tsx`）：两组卡片「已开启 N」「已关闭 N」，第一组标题右侧「+」添加；标题下一行说明：「接口整台电脑共用。在 Claude Code、Codex 的设置里打开「使用第三方接口」后，就能用这里开着的接口里选好的模型；关掉某一家，所有 Agent 都不再用它。」
- 每行（照 `provider-row-*`）：28px 头像（名称首字，实现可换成图标）· 名称 · 状态行（状态点 + 「支持的格式 · 主机名 · 已选 N 个模型」；冷却中 / 需要检查时在后面接状态色文字，如「冷却中，12 分钟后恢复」「key 无效，需要检查」）· 接口开关 · 进入详情的箭头。
- 冷却中的行，状态文字后加一个「立刻恢复」小按钮（Q18）。

### 2. 添加接口（弹窗）

- `AdaptiveModalSheet`，标题「添加第三方接口」。字段顺序：名称 → API key → 地址 + 「自动检测」按钮 → 三种格式地址框。
- 地址框下说明：「填好 key 后点「自动检测」，Osuna 会用三种请求格式各试一次，把能用的地址填到下面。」
- 格式地址框（浅底分组）：Anthropic 格式地址 / OpenAI Chat 格式地址 / OpenAI Responses 格式地址；每项标签右侧显示检测结果「✓ 检测通过」（成功色）或「未检测到」（弱色）；上游回 401 / 403 时三项改显示「key 无效」（危险色）并在 key 框下标红提示（10 票 Q4）；可手改；留空 = 这家不用这种格式；至少填一个才能保存。
- 底部说明：「key 只填一次，三种格式共用。保存后进入这个接口的详情页，拉取上游模型、按 Claude / GPT / Gemini 分组挑选。」主按钮「保存并拉取模型」。
- 弹窗里不挑模型。编辑连接复用同一弹窗（标题「编辑连接」，主按钮「保存」，key 留空 = 不改）。

### 3. 接口详情页

- 面包屑「第三方接口 / 名称」。版式照提供方详情页（`provider-detail/index.tsx`）。
- 头部：头像 · 名称 · 状态徽标（`StatusBadge`）· 「支持的格式 · 已选 N 个模型」；右侧「已开启」+ 接口开关、「测试连接」、⋯ 菜单（编辑连接 / 删除）。冷却中时徽标旁出现「立刻恢复」。「测试连接」对每个已填地址各测一次、分别显示结果，认证失败显示「key 无效」（10 票 Q4）。
- 「连接」区：标题右侧「编辑」；一行说明「key 三种格式共用。每次请求：Agent 自己的格式这家有就原样转发；Claude 模型有 Anthropic 地址时一律走它（保住缓存）；都没有就由 Osuna 翻译。」卡片行：三种格式地址（等宽字体；未填显示「未填，不用这种格式」）、API key（打码）。
- 「模型」区：标题「模型 已选 N / 共 M」，右侧「拉取于 x 分钟前」「重新拉取」「手动添加」。卡片内：搜索框，下面**左右两栏**：
  - 左栏：家族目录，每项「厂商图标 · 家族名 · 已选/总数」，当前项浅灰底。顺序 Claude、GPT、Gemini、DeepSeek、Kimi、GLM、通义千问、其余已识别家族、其他。
  - 右栏：当前家族标题「图标 · 家族名 · 已选 x / y」+ 右侧灰字「全选」（已全选时「全不选」）；每个模型一行：模型名（普通字体，不用等宽）+ 右侧小开关；关着的模型名变淡。**不用勾选框**。
  - 拉回来的模型默认全部关着（U4）。「重新拉取」只把新模型关着加进清单，已开的全部保留；上游不再提供的在行尾加弱色小字「上游清单里没有了」；「手动添加」的同样保留（10 票 Q3）。搜索时左栏只列有命中的家族、计数照旧，右栏显示当前家族的命中项。
  - 家族按模型名最后一个 `/` 之后的前缀识别（照 magpie `internal/agent/icons.go:15-28`：claude；gpt/o1/o3/o4/codex；gemini/gemma；deepseek；grok；kimi/moonshot；glm；qwen/qwq；mistral 系；minimax；mimo；step），认不出归「其他」。厂商图标借 magpie `internal/gui/assets/icons/`（MIT），实现时注明来源。
- 「Claude 档位映射（可选）」区：说明「Claude Code 里选 opus / sonnet / haiku / fable 时，走这家接口就换成右边的模型；不填就原样发过去。」四行 Opus / Sonnet / Haiku / Fable，右侧下拉（不映射 + 本接口已选模型）。

### 4. Claude Code / Codex 提供方详情页

「第三方接口」区只剩一张三行卡片：

1. 「使用第三方接口」+ 总开关；说明「打开后，Claude Code 能用「第三方接口」页里开着的接口的已选模型；关掉就回到官方。」没有「开着且已选模型」的接口时开关不可打开，说明改为「先到「第三方接口」页开启一家并勾选模型」（10 票 Q2）；daemon 以 socket 监听时开关禁用并说明原因（05 票）。
2. 「默认模型」+ 下拉；说明「终端新会话、第一次新建对话从它开始」。下拉只列光秃秃模型名（开着的接口已选模型合并去重）。总开关关时隐藏。
3. 「管理第三方接口 ›」入口行，说明行汇总「N 个开着 · 某家冷却中，x 分钟后恢复」。

现有的「官方 / 使用」单选行、行内编辑删除、健康提示 Alert 去掉（健康问题仍由 05 票的启动重写处理，界面另议时再加）。

### 5. 聊天里的模型选择器（按文字定，未画）

Claude Code / Codex 下按接口名分组（创建顺序），组标题是接口名；每个模型名前加家族小图标；同名模型在各家下各出现一次；只列开着的接口的已选模型。选了哪家下的模型就走哪家（`slug/模型名` 内部写法，界面不显示）。

### 6. 删除接口

`confirmDialog`，正文写明影响：「会从所有 Agent 的可选模型里去掉。Claude Code 的默认模型会从 a 改成 b」（或「…将回到官方」）。关掉接口开关、关掉模型小开关时不弹确认，除非这一步会让某个 Agent 一个能用的模型都不剩而回到官方，此时弹同样的确认框写明「<Agent> 将回到官方」（10 票 Q1、Q2）。

## 状态词

| 状态 | 颜色 | 出现位置 |
|---|---|---|
| 可用 | 成功色 | 列表状态点、详情徽标 |
| 冷却中 · x 分钟后恢复 | 警告色 | 列表行文字、详情徽标、Agent 页入口行 |
| 需要检查（key 无效 / 无权限） | 危险色 | 列表行文字、详情徽标 |
| 已关闭 | 弱色 | 列表「已关闭」组、详情开关 |

取代旧的「使用中」「已暂停」。

## 用户的喜欢与不喜欢

- 不喜欢：接口放在某个 Agent 的页面里；只画列表不画「添加 → 拉模型 → 挑模型」这一层；「协议」单选让人以为三种格式要分别配 key；模型列表一行一个、等宽字体、蓝色方框勾选、蓝色链接（「丑」）。
- 喜欢：magpie 的三层结构；拉取模型按家族分组；C 的左家族右模型；B 的小开关。
- 明确要求：开关而不是勾选（04 票 D3 起一贯如此）。

## 不做

- composer 上方「当前实际在用」小横条（Q17 作废）。
- 按 Agent 精简模型（magpie 的隐藏 / 只用挑选的模型）；预设中转站清单；按模型指定走哪种格式。以后需要再加。

## 验收重点

- 列表、详情、弹窗、Agent 页四处都与现有设置页同组件、同密度，不出现新的视觉语言。
- 模型列表在 200+ 模型时左栏不滚出卡片外、右栏可滚动；搜索命中跨家族时左栏正确过滤。
- 所有状态词与 zh-CN 文案走 i18n（`docs/i18n.md`），英文为源。
- 浅色、深色主题各取证一次；Electron 与浏览器 Web 各取证一次。
