# 10 — 人民币和「万 / 亿」

**What to build:** 用量页概览卡头部多一个选项菜单：「货币：美元 / 人民币」（每台设备各记，默认美元），旁边一行写「1 美元 = 7.12 元 · {时间} 取得」或「尚未取到汇率，暂按 7.2 计算」；选人民币后用量页、请求列表、会话列表、每轮花费、Agent 用量卡的估算成本都显示人民币。中文界面多一个「用『万 / 亿』显示大数」Switch（默认关），开着时 token 数显示「1.2 万」「3.4 亿」。

**Blocked by:** None — can start immediately
**Status:** ready-for-agent
**Impl:** doing

- [ ] 新 RPC `usage.exchange_rate.get.request` / `.response`：回汇率、取得时间、是否缺省值；daemon 缓存存盘，一天内不重取；向 `open.er-api.com` GET、不带认证、Osuna 自己的 User-Agent、15 秒超时；失败回上次的值；从未取到回 7.2；价格表自动更新关掉时不发请求。
- [ ] 只在客户端选了人民币时调用；daemon 不支持时货币选项不出现。
- [ ] 端到端测试（本机假汇率服务）：首次取、一天内不重取、失败回上次、从未取到 7.2、自动更新关掉不发请求、User-Agent。
- [ ] 价格表、CSV、接口余额不换算。
- [ ] 万 / 亿只影响 token 数、不影响金额；英文等非中文界面不出现开关；数字格式的已有单元测试加用例。
- [ ] 文档：`docs/usage.md`「Outbound requests」加汇率请求（发给谁、带什么、何时、怎么关）；`docs/data-model.md` 汇率缓存。
- [ ] 浏览器测试：切人民币后各处金额为「¥」与汇率说明；中文界面开万 / 亿；英文界面没有该开关。
- [ ] 9 种语言的新文字齐全。
- [ ] UI：用量页选项菜单 / 人民币已选、万 / 亿开 / 1280 与 390 — 汇率说明一行可见，开关是 Switch，菜单照 `docs/menus.md`（窄窗口为底部弹出）。

参考：prd 第 20–23、28 条，用户故事 23–29。
