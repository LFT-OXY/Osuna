# 06 — 导出 CSV

**What to build:** 请求标签底部的「导出 CSV」把符合当前筛选的全部请求（不只当前一页）导出：列表的列 + 推理 token、失败原因、尝试次数、回复编号、会话编号，金额用美元。桌面版弹保存窗口，浏览器直接下载，手机走系统分享。

**Blocked by:** 05
**Status:** ready-for-agent
**Impl:** doing

- [ ] 新 RPC `usage.requests.export.request` / `.response`：同一组筛选，回 CSV 文字；端到端测试检查列名、行数等于筛选总数、金额为美元、逗号与换行正确转义。
- [ ] 导出进行中按钮转圈并禁用；失败时按钮旁留原因与「重试」，直到重试或关掉；成功不弹窗。
- [ ] 浏览器测试：导出成功（下载内容正确）与失败（daemon 回错）两种。
- [ ] 9 种语言的新文字齐全。
- [ ] UI：请求标签底部 / 导出失败 / 1280 与 390 — 原因和「重试」留在按钮旁。
