# 08 — 接口页「最近异常」

**What to build:** 接口详情页多一块「最近异常」：这家最近 20 次失败、被换走或导致冷却的请求（时间、模型、事由，如「额度用完，冷却到 15:30」「换到了 B 接口」），重启后还在；底部「在请求列表里看全部」跳到用量页「请求」标签并按这家筛选。

**Blocked by:** 05
**Status:** ready-for-agent
**Impl:** ready

- [ ] 新 RPC `provider.api_endpoint.recent_problems.request` / `.response`，读逐条记录；端到端测试：内容、上限 20、重启后还在、只含这家。
- [ ] 详情页开着时随 `usage.updated` 重读。
- [ ] 没有记录时写「最近没有异常」；读取失败时分区内留原因与「重试」。
- [ ] 「在请求列表里看全部」是次要按钮样式（不是蓝色链接），跳转后筛选已设好。
- [ ] 浏览器测试：有记录、空、失败重试、跳转。
- [ ] 9 种语言的新文字齐全。
- [ ] UI：接口详情页 / 有记录与空两种 / 1280 与 390 — 「最近异常」分区与跳转按钮可见。
