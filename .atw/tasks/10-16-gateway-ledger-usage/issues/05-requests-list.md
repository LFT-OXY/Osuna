# 05 — 请求列表

**What to build:** 用量页明细卡片在「每日 / 每月 / 项目」后多一个「请求」标签：逐条列出请求（时间、Agent、模型、接口、输入、输出、缓存读、缓存写、估算成本、耗时、首字等待、出字速度、状态），直连官方的调用也列（耗时等留空）；可按状态（全部 / 失败 / 换过家）、经过中转站 / 直连、Agent、接口、模型筛选并搜索；每页 100 条翻页；点开一行看每次尝试。逐条记录保留 30 天、最多 200 MB。

**Blocked by:** 02
**Status:** ready-for-agent
**Impl:** ready

- [ ] 直连调用的逐条行从 CLI 会话记录读出（时间、Agent、模型、token、会话、项目），和账本行一起按天分文件存。
- [ ] 修剪：超过 30 天或合计超过 200 MB，从最旧的一天整天删，最多每小时一次；汇总不受影响（端到端测试用固定时钟验证）。
- [ ] 新 RPC `usage.requests.list.request` / `.response`：时段、筛选、偏移与条数，回逐条记录与总条数，每条带尝试明细。
- [ ] 端到端测试：各筛选、搜索、分页、总数、尝试明细内容。
- [ ] 浏览器测试：筛选、翻页、展开一行；加载中骨架；空状态「没有符合条件的请求」。
- [ ] 文档：`docs/usage.md` 两层存储与保留；`docs/data-model.md` 逐条记录文件。
- [ ] 9 种语言的新文字齐全。
- [ ] UI：用量页请求标签 / 有数据、空、加载三种 / 1280 与 390 — 宽 390 只显示时间、模型、接口、状态、成本，其余在展开行，不横向溢出；状态列写「失败（原因）」「换过 N 家」。
