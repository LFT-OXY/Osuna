## 第二轮

- Q7 合并规则：同一次调用账本与会话记录按回复编号（Claude `message.id`、Codex `response_id`）对上时合成一条——token、接口、耗时、首字等待取账本；项目、会话、轮次取会话记录（magpie 同样以网关行为准并补上会话编号）。只在账本里的（如失败请求）算「未知项目」；只在会话记录里的即直连。Pi / OMP 同规则：能按编号对上就合，对不上则照 magpie 跳过会话记录里 provider 是 Osuna 中转站的那条。推翻总 PRD 实现决定第 4 条「只算账本那条」的措辞。
- Q8 用量页新增「接口」分法，与来源、模型、项目并列；每家接口一张卡片 + 「官方」卡片；可按接口筛选。
- Q9 升级前走过中转站的历史归入「官方」组（英文 Official），只在 `docs/usage.md` 说明，界面不加说明。
- Q10 两层存储：15 分钟汇总加「接口」列与速度用数，永久保留；逐条请求记录（请求列表、接口页记录、CSV）保留 30 天、最多 200 MB，超了从最旧的一天删起（照 magpie 路由历史）。
- Q11 价格倍率在接口编辑窗口填，0–1000、最多三位小数，不填按原价；自定义价格优先、不乘倍率；改倍率后历史花费按新倍率重算（成本本就读时现算）。
- Q12 货币：用量页选项里「美元 / 人民币」，默认美元，不随界面语言，每台设备各自记；所有显示估算成本的地方都换算（用量页、请求列表、每轮花费）；价格表与 CSV 保持美元。「万 / 亿」开关默认关，只在中文界面显示与生效（照 magpie）。
- Q13 速度照 magpie：首字等待 = 中转站收到请求到回复第一个内容；出字速度 = 开始出字后的输出 token / 秒，组内按 token 加权；剔除过短与攒着一次吐出的；不设最小样本，标「基于 N 条」；分组可切 接口 / 模型 / 模型 · 接口 / Agent。只有经过中转站的调用有速度。
- Q14 接口页列这家最近 20 次出过事（失败、被换走、进入冷却）的请求：时间、模型、事由；底部「在请求列表里看全部」跳到按该接口筛选的请求列表。
- Q15 用量页每张接口卡片显示一行余额（子任务 4 的读数），不换算货币。
