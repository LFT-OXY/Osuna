# 问答已定决策（2026-09-29）

现状与参考项目见 [reference-projects.md](reference-projects.md)。

## 范围

1. 只做 Electron 桌面端与浏览器 Web 端的字体选择器；原生 iOS/Android 保持现状（另开任务）。
2. 字体来源仅为系统字体枚举（`queryLocalFonts`）+ 自定义输入兜底；不打包字体、不走 CDN。
3. 不加入行高、连字、字重、字体平滑、Electron 缩放持久化。
4. 存储维持客户端本地 `AppSettings`（每设备），不改 daemon / protocol。

## 设置项

5. 保留现有 5 项（界面字体、界面字号、内容字号、代码字体、代码字号），新增「终端字体」「终端字号」。不加 Composer 字体，不做 Simple/Advanced 两档。
6. 终端字体 `""` = 跟随代码字体；选择器首项「跟随代码字体」。终端字号 `null` = 跟随代码字号，输入框留空，占位符显示当前代码字号。
7. 终端字号全平台显示（原生终端也生效）；终端字体行只在桌面/Web 显示（原生仍受 Menlo/monospace 白名单）。

## 字体栈语义

8. 用户字体前插到默认栈：`<用户值>, <默认栈>`，不再整串替换。老用户手写的完整栈不迁移，前插后仍有效。
9. 默认等宽栈统一为 `theme.ts` 一处，代码区、diff（含 web 的硬编码 `DEFAULT_MONO_STACK`）、终端共用；终端在末尾追加本机 Nerd Font 名作符号回退（不打包，未装则图标显示方框）。

## 选择器交互

10. 复用 `components/ui/combobox.tsx`：触发按钮显示当前字体名并以该字体渲染；展开时（用户手势）调用 `queryLocalFonts()`；首项「默认」（终端为「跟随代码字体」），其后可搜索系统字体，每项以自身字体渲染；开启 `allowCustomValue`。
11. 枚举不可用（不支持 / 拒绝 / 非安全上下文）时退化为搜索框 + 自定义值。
12. 「默认」只显示「系统默认」，不反查实际字体名。
13. 字段仍为字符串；选中写入单个字体名（必要时加引号）；已存多字体栈作为自定义值原样显示。

## 校验

14. 代码字体与终端字体下拉只列等宽字体（canvas 测宽）。
15. 自定义值：本机未检测到或（代码/终端）非等宽时，只在行下提示，照常保存。

## 预览与重置

16. `AppearancePreview` 增加静态终端样例（终端字体/字号，含一个 Nerd Font 提示符图标），不起真实 xterm。
17. 字体行通过选择器「默认 / 跟随代码字体」恢复；字号行非默认时显示重置图标按钮（参照 `keyboard-shortcuts-section.tsx:229`）；无全局恢复默认。

## 术语
