# 04 — 上次读数：暂时失败时仍有参考

**What to build:** 对方忙或断网时，详情分区显示上次的读数，并标「X 分钟前」；列表行照常显示上次的余额。重启 Osuna 后上次读数还在。改了接口的地址、key 或余额设置，或删了接口，它的上次读数作废。

**Blocked by:** 01
**Status:** ready-for-agent
**Impl:** done

- [x] 每家最近一次成功的读数（数字、窗口、读数时间，不含 key 与令牌）存进 daemon 接口数据目录下的单独文件，原子写入，坏了当作没有（`docs/data-model.md`）。
- [x] 暂时性失败（429、5xx、超时、网络错误）时读余额 RPC 返回上次读数并标明是旧的；别的失败不回旧读数。

- [x] 端到端测试：暂时失败回旧读数、重启后还在、改设置后作废、别的失败不回旧读数；读数文件里没有 key 与令牌。
