# 07 — 切换确认，以及编辑、删除当前启用的接口

**What to build:** 以下三种操作都要先弹确认框：切换（启用某个接口或切回官方）、保存对当前启用接口的修改、删除当前启用的接口。确认框写明两件事：

- 该提供方有 N 个正在运行的会话会立即改用新配置。Codex 的措辞是「可能受影响」。
- 终端里的 CLI 也会跟着切换。

另外：

- 保存对当前启用接口的修改后，立即按新配置重新写入文件。
- 删除当前启用的接口时，先切回官方，恢复原值，然后再删除。

**Blocked by:** 01, 02

**Status:** ready-for-agent
**Impl:** done

实现时确定：「正在运行」统计该提供方下还活着的会话（initializing / idle / running），只算本提供方，不含继承 claude 的自定义提供方；确认前先重新拉一次列表再判断；「重新应用」同样带影响说明。
