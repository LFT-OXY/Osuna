# 08 — 会话模式记录与各处提示

**What to build:**

- **会话模式**：每个 Agent session 在创建时记下当时所处的模式，也就是某个接口的 id，或者「官方」。老记录没有这个字段，按「官方」处理。用户恢复会话时，如果记录的模式和当前模式不同，会话里显示一次提示，例如「此会话创建于第三方接口 X，当前为官方，可能无法继续」。
- **套餐用量**：Claude Code 或 Codex 启用了第三方接口时，对应的套餐用量旁边标注「当前使用第三方接口，此额度不代表实际消耗」。
- **自定义提供方**：Claude 启用了第三方接口时，在继承 `claude` 的自定义提供方那一行显示提示，说明它们也会走当前接口，因为 `settings.json` 的 env 优先级高于进程环境。
