# 05 — 模型选择器随模式切换

**What to build:** Claude Code 或 Codex 启用了第三方接口后，Osuna 的模型选择器只列出这个接口里勾选的模型（包括手动添加的），传给 CLI 的是这些模型的真实 id。新开的会话默认选中该接口的默认模型，官方模型不再出现。切回官方后，模型选择器恢复成原来的列表。

每次模式变化，包括启用、切回、编辑当前启用的接口，daemon 都会刷新对应提供方的快照，客户端随之更新。第三方模式下，Claude 从 `settings.json` 追加模型的现有逻辑不能产生重复或多余的条目。
