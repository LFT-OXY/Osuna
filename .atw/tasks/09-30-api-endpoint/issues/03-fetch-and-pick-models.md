# 03 — 从上游拉取模型并勾选

**What to build:** 在新建或编辑第三方接口时，用户填好 URL 和 key 后点「拉取模型」，daemon 就从主机向上游请求模型列表。用户在可搜索的列表里勾选要用的模型，并从中指定一个默认模型。只保存勾选的模型，之后可以重新拉取、重新勾选。

上游不支持列出模型时，给出明确提示，并退回到手动添加模型 id。

Claude 接口另有一块可选的「模型映射」：Opus、Sonnet、Haiku、Fable 四档，每档都只能从已勾选的模型里选。填了的档位写进 `settings.json` 对应的 `ANTHROPIC_DEFAULT_*_MODEL`，没填的档位不写。映射同样属于负责的键，切回官方时会恢复原值。
