# 02 — 桌面端提供方按钮与提供方列表

**What to build:** 在桌面/Web 草稿 Composer 的工具栏上，模型按钮左边出现一个只显示当前提供方图标的按钮。点开是提供方列表：状态为 `ready`/`loading` 的已启用提供方平铺显示；状态为 `error`/`unavailable` 的折叠在「More agents (N)」下，展开后仍可选中；未启用的提供方不出现；当前项打勾。在草稿里切换提供方后，模型恢复为该提供方上次的选择，没有记录就用默认模型。运行中的 Agent 上，这个按钮只显示图标，处于禁用态。本 ticket 不改模型菜单，它此时仍能跨提供方浏览。

**Status:** ready-for-agent
**Impl:** done
**Blocked by:** none

- [x] provider-selection 模块新增提供方分组纯函数：输入提供方快照，输出「平铺」和「更多」两组，保持原有顺序并排除未启用的提供方；有对应单元测试
- [x] 草稿工具栏的顺序为：提供方图标按钮、模型、思考、模式；按钮带包含提供方名字的无障碍标签和悬停提示，可以用键盘打开和选择
- [x] 提供方列表每行显示品牌图标（取 brand tone）和名字，当前项打勾，并有「More agents (N)」折叠区
- [x] 列表加载中时，按钮显示占位图标
