# 12 — 「用量」页的布局原型

**Type:** prototype
**Blocked by:** None
**Status:** resolved

## Question

用 `atw-prototype` 做一个可丢弃的 RN 页面原型（或静态 HTML 草图），确定：卡片顺序与栅格（桌面双栏 / 移动单栏）、周期选择器形态、来源卡片样式（参考截图：图标 + 名称 + 占比 + 模型数）、趋势图与热力图在 svg 自绘下的样子、每日明细表展开会话行的交互、价格表区块、Plan usage 区块位置、Host 筛选的位置及其中「需要更新主机」/「未计入」Host 的呈现；多 Host 时项目行的 Host 徽标；回填进度的形态（页面顶部条 / 区块内提示）。协议形状已由 08 号票定死（`usage.report.get` 一次带全部区块，含 `backfill` 状态），原型按其响应形状取数。产出：原型路径 + 用户认可的布局描述，作为 prd 的 UI 章节输入。

## Answer

用户 2026-09-18 确认，原型 `prototype/usage-page.html`（静态 HTML，假数据按 08 号票响应形状生成；打开即看，无变体）。**视觉整体照抄参考项目 TokenTracker 的 dashboard**（布局与组件样式），不按 `docs/design.md` 的 Paseo 令牌重画；prd 的 UI 章节需写明本页是独立视觉岛，或列出参考样式与 Paseo 令牌的映射。

### 布局

- 桌面：12 栅格，左 4 / 右 8。左列自上而下：统计面板、热力图、使用趋势、Plan usage；右列：用量总览、数据明细。两列末尾卡片拉伸到同一底边，数据明细表格填满卡片、超出内部滚动。
- 手机：单列，顺序为用量总览 → 数据明细 → 左列四卡。
- 卡片：白底、1px 灰描边、12px 圆角、20px 内边距；卡片标题 14px/500 灰色。

### 各区块形态

- **用量总览**：头部左侧周期页签（日 / 周 / 月 / 总计 / 自定义，自定义选中后页签文字变成区间），右侧 ‹ › 翻页、回填 pill、Host 筛选、刷新按钮；自定义时页签下方出两个日期输入。中央 "TOKEN 总数" 小标签 + 72px 粗体总数 + 绿色估算成本（带 ⓘ）+ 区间文字 + "估算成本 · 按公开 API 价格计算"。下方来源分布条（6px 圆角横条，按来源占比着色）→ 来源卡片栅格（`auto-fill, minmax(140px, 1fr)`）：图标 + 名称 / 占比（18px/600）/ "N 个模型"；首张"全部"卡。点任一卡片在栅格下方展开该来源的模型明细（名称 / tokens / 估算成本 / 占比 + 3px 细条），再点收起。无价格模型在名称后带琥珀 pill "无价格数据"。
- **统计面板**：四格（7 天 / 30 天 / 平均（30 天内活跃日均）/ 会话数）灰底圆角块；Top 3 模型（序号圆点 + 名称 + 占比）；页脚 "开始使用 <首个活跃日>" / "活跃天数 N 天"。
- **热力图**：固定最近 26 周（手机 20 周），与周期无关；**周一起**（Q20，不跟参考项目的周日起）；行标 一…日，列顶月份；5 级绿色阶（level 0 灰）；右上 2D/3D 分段（v1 只做 2D，3D 不做）+ 时区标签；底部 "少 ▪▪▪▪▪ 多"。悬停显示日期与 token 数。
- **使用趋势**：按来源堆叠柱，柱间 2px；日/周/月周期按天一柱，"总计"按月一柱，"日"周期按小时；周期内未来日画灰色矮"预测值"柱；4 条横向浅网格线；x 轴小号等宽日期；页脚首尾日期。右上放大按钮 v1 不做。**堆叠维度切换（按来源 / 按模型）保留**，放在卡片标题右侧用 tiny 分段控件（原型未画，按参考项目 TrendMonitor 的做法）。
- **Plan usage**：左列底部卡片，标题 "Plan usage · 已用" + 右侧更新时间；每个 provider 一组：图标 + 名称（含套餐），每行 = 窗口标签（11px）/ 6px 细横条（按已用比例绿 / 琥珀 / 红，另有一条 2px 进度刻度线）/ 百分比 / 重置倒计时；余额型条灰色，前有 "重置" 小标。
- **数据明细**：卡内三页签 每日细目 / 按月 / 项目用量。
  - 每日细目：表格列 日期 ▼ / 总计 / 输入 / 输出 / 缓存 / 推理 / 会话 / 估算成本；点行展开该日会话列表（参考项目会话页行样式：来源图标、会话标题、来源 pill、多 Host 时 Host 徽标、项目 · 模型 · 时间 · 时长、↑↓缓存明细；右侧 Token / 成本 / 轮次 三个 dl + "打开" 圆角按钮 → 跳 Session history 打开/导入）。
  - 按月：列 月份 / 总计 / 输入 / 输出 / 缓存 / 会话 / 估算成本。
  - 项目用量：右上 前 3 / 前 6 / 前 10 分段；行 = 首字母头像（固定色表）+ owner/name + 非 git 标签 + 多 Host 时 Host 徽标 + 来源小图标列；右侧 tokens + 4px 绿条；点行展开 cwd 列表（左侧竖线缩进）。
- **价格表：不在本页**，挪到主机设置页（Plan usage 搬走后腾出的位置）。形态：卡片标题 + "每百万 token 美元 · LiteLLM 快照，N 小时前更新，M 个模型"；右上 自动更新开关 + 立即刷新；表格列 模型 / 输入 / 缓存读 / 缓存写 / 输出 / 来源 / 操作；已计价行末 "自定义价格" 幽灵按钮，无价格行四格输入 + 保存，名称后琥珀 pill "无价格数据 · 估算 $0"。

### 跨切面

- **Host 筛选**：总览头部按钮（服务器图标 + 当前选择 + ▾），下拉列表：首项 "全部主机" 带灰 pill "N 台计入"；正常主机绿点可选；`features.usage=false` 的主机灰字不可选 + 琥珀 pill "需要更新主机"；未连接主机灰点不可选 + 灰 pill "未计入"。只有一台主机时不显示。
- **回填进度**：总览头部一枚琥珀 pill（呼吸点 + "回填中 312 / 1,859"），悬停提示文件数与"最近的日期先补齐"；无页顶横幅、无卡内提示；done 后 pill 消失。
- **配色**：来源固定色表 Claude Code `#d97757`、Codex `#3b82f6`；Pi / OMP 按后端取固定表（anthropic、openai、ollama、github、xai…各一色），未知后端 `hsl(150 + idx*40, 60%, 45%)` 兜底；同一后端在 Pi 与 OMP 下同色。热力图绿阶 `#ebedf0 / #a7f3d0 / #6ee7b7 / #34d399 / #10b981`（暗色 `#121212 / #065f46 / #059669 / #10b981 / #34d399`）。品牌绿 `#059669`（估算成本、进度条）。
- **数字格式**：总览大数字与表格用千分位全量；统计四格、来源展开、项目、会话用 K/M/B 缩写（一位小数）；成本两位小数。

### 对其他票的修订

- 08 号票：热力图不再从报表 `days` 派生。`usage.report.get` 响应新增 `heatmapDays: [{ day, totals }]`，固定返回按请求时区的最近 182 天，独立于 from/to（与 last7/30 同理）。
- 09 号票："价格表区块在「用量」页" 改为 "在主机设置页"；`usage.pricing.*` RPC 不变。
- 访谈 Q9 "主机设置页留入口" 的答案：主机设置页保留一个 **价格表** 区块，Plan usage 区块整体搬入「用量」页。

### 否决的替代方案

按 Paseo `docs/design.md` 令牌重画的三个变体（仪表盘双栏 / 720 单列 / 分页签）——用户否决，要求照抄参考项目。价格表放在用量页右列底部——用户否决，两列底边不齐。
