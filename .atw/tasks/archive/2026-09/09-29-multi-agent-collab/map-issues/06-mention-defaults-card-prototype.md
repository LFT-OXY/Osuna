# 06 — "提及智能体默认值"设置卡原型

**Type:** prototype
**Blocked by:** 05
**Status:** resolved

## Question

在 Host → Agents 页（`HostAgentsPage`，现有"注入 Osuna tools"、浏览器工具、追加系统提示三张卡）新增"提及智能体默认值"卡片应长什么样。字段已由 05 号票定下：每个已启用 provider 配模型、思考档位、模式三个下拉，每项首项为"默认（X）"清除覆盖；Agent profile 不进卡片。要定：每 provider 一行还是 codeg 式每 provider 一个标签按钮、一次编辑一个；思考档位随模型切换时的联动；失效值"不可用，将使用默认"的呈现；即时保存还是保存按钮；Osuna tools 关闭或老 Host 时卡片状态；手机与桌面布局。做本地 HTML 静态原型放 `prototype/`，遵循 `docs/design.md`，用户看后拍板。

## Assets

- 原型：`prototype/mention-defaults-card.html`（A 行内三下拉 / B 可展开行 / C codeg 式标签+保存 / D 行+弹窗；右侧控制台切场景、看配置与路由解析）

## Answer

2026-09-30 用户看原型后拍板：方案 B，其余按推荐。

1. **布局**：Agents 页"Agents"区块之后单独一个 `SettingsSection`「提及智能体默认值」，说明放标题的 `info` 提示。卡片里每个已启用 provider 一行：图标、名称，下面一行摘要（如"Sonnet 5 · 高 · 其余默认"，全未设为"全部使用默认"，含失效值时摘要用警示色并带 ⚠），行尾展开箭头。展开后是三条标准设置行（模型、思考、模式），控件是 `DropdownTrigger` + `DropdownMenu`，行缩进到名称的文字对齐线；有覆盖时底部出现 ghost 按钮"全部恢复默认"。可同时展开多行。手机与桌面同一结构，不另做布局。
2. **保存**：即时保存，每次选择就 `patchConfig` 写该 provider 的 `mentionDefaults`，与同页其他卡片、元数据生成页一致；没有保存按钮。
3. **下拉内容**：首项"默认（X）"清除覆盖，X 是此刻解析出的值；思考档位的默认项随当前生效模型。
4. **思考档位联动**：换模型后，已选档位不属于新模型 → 自动清回默认，并在思考行下短暂提示"思考档位已随模型改回默认（X）"；新模型没有思考档位 → 思考下拉显示"不支持"并置灰（已存的档位清除）。provider 没有模式时，模式下拉同样"不支持"置灰。
5. **失效值**：触发器照显已存原值，前加 ⚠、警示色描边；该行下写"<值> 不可用，将使用默认（X）"；打开下拉时原值排在选项最前，标"（不可用）"。
6. **快照状态**：加载中 → 该 provider 的下拉置灰带小转圈，摘要"加载模型列表..."；出错 → 下拉置灰显示原值，红色一行"无法读取模型列表，发送时原样使用已保存的值"（对应 05 号票的原样透传）。
7. **Osuna tools 关闭**：卡片照常可编辑，卡片顶部一行提示"Osuna tools 已关闭，@ 提及智能体暂不可用。这里的设置在开启后生效"。
8. **老 Host**（无能力开关）：整张卡片只有一行"更新 Host 后可以设置提及智能体默认值"。
9. **Agent profile**：不进卡片（05 号票）。
10. **已知分歧**：`profile-form-model.ts:245-254` 为 Agent profile 表单删掉过"Provider default"虚拟项；这里有意保留"默认（X）"，因为 mention defaults 的未设置语义就是跟随 provider 默认，括号里显示当前解析值以减轻误读。不重开 05 号票。
