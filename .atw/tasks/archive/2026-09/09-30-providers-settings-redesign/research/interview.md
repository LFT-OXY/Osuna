# 决策访谈记录

参考：OpenCode 的提供商设置（三栏：设置侧栏 / 提供商列表 / 详情：认证、连接详情、可用模型），T3 Code 的提供方设置（左列表带开关与认证状态，右侧分组卡片：显示名称、运行时、环境、模型）。

## 现状事实（2026-09-30）

- 页面：设置 → 主机 → 提供方，`packages/app/src/screens/settings/providers-section.tsx`，放在 720 宽的居中列里。上面一张提供方卡片（`ProviderRow`：图标、名称、模型数或错误、状态点或「如何安装」、开关、自定义提供方的 ⋯ 菜单、›），下面单独一节「添加提供方」（ACP 目录，`ProviderCatalogList`）。
- 详情：全局 `ProviderSettingsHost`（`app/_layout.tsx`）挂一个 `AdaptiveModalSheet`（`components/provider-diagnostic-sheet.tsx`），内容依次是安装指引（仅未安装）、第三方接口（仅 Claude/Codex，按 `apiEndpoints` 能力门控）、模型（已发现和自定义，带搜索）。底部栏：更新时间、添加模型、诊断、刷新。添加模型和诊断各自再开一层子弹窗。
- 详情入口有两个：设置页的提供方行，以及 composer 模型选择器里的齿轮（`components/model-browser.tsx:95`，叠加在模型选择器的浮层上）。
- 设置里已有子路由先例：`/settings/hosts/[serverId]/projects/[projectId]`。
- daemon 不上报 CLI 版本、认证状态和账号套餐。客户端通过协议能改的提供方配置只有 `enabled`、`additionalModels`、`paseoTools`。「隐藏模型」这个概念不存在。
- `docs/design.md` §7 规定设置详情页最大宽 720；§9 规定列表+详情照搬设置外壳，新形态要走设计评审。

## 第 1 轮决定

1. 范围：只重排现有能力（列表、安装指引、第三方接口、模型、诊断、添加提供方）。版本号、认证、模型显隐、运行时配置编辑都不做，原型里也不占位。
2. 桌面端：页内列表+详情，取消弹窗。紧凑端：列表 → 推入全屏详情。
3. 「添加提供方」改成列表顶部的「+」，点开 ACP 目录弹窗；列表列只放已有提供方。
4. 原型：本地静态 HTML，放在本任务的 `prototype/` 下，只给路径不发布。
5. 已建本任务。

## 第 2 轮决定

6. composer 模型选择器的齿轮仍然弹窗，弹窗里放和设置页同一个详情组件，只换外框。
7. 选中的提供方进 URL：`/settings/hosts/:serverId/providers/:provider`，照搬项目页的子路由。桌面端进入时 redirect 到第一项。改路由前先读 `docs/expo-router.md`。
8. 宽度：列表列 280，详情列最大 720，两列整体居中；内容区放不下 280+400 时退回栈式布局。写进 `docs/design.md` §7/§9，不开 ADR。数值等原型出来再调。
9. 列表行：图标 + 名称，下面一行状态点加文字（「N 个模型」「未安装」「出错」「已停用」「第三方接口：{名称}」），行尾开关。桌面端去掉 › 和 ⋯，选中行高亮；紧凑端保留 ›。去掉「如何安装」链接。开关只在列表里。
10. 详情：头部是图标 + 名称 + 状态徽章，右侧「刷新」和 ⋯ 菜单（诊断；自定义提供方另有删除）。下面依次是错误卡（出错时）、安装指引（未安装时）、第三方接口（Claude/Codex）、模型（节标题带数量和「更新于 X」，右侧「添加模型」；卡片内是搜索、已发现、自定义）。取消底部栏。
11. 诊断和添加模型都改成就地展开：诊断是最底部一节，有「运行诊断」按钮和可复制的结果，⋯ 菜单里的「诊断」滚动到这一节并运行；添加模型在模型节里展开一行输入框加「添加」按钮。页面里不再有弹窗叠弹窗。

## 第 3 轮决定

12. 在「+」目录弹窗里添加提供方后，关掉弹窗，选中新加的这一行（桌面端在右侧显示详情，紧凑端推入详情）。
13. 原型覆盖以下画面：
    - 桌面端：Claude Code 使用中第三方接口、Codex 官方模式、Pi 未安装、OpenCode 出错、Copilot 已停用、自定义提供方、诊断节展开、添加模型展开、「+」目录弹窗；
    - 窄桌面栈式布局；
    - 紧凑端列表页和详情页；
    - composer 齿轮打开的弹窗外框；
    - 以上都有浅色和深色。

    **用户要求原型与真实 App 一比一还原**，精细美观，不计 token 成本：token、字体、组件尺寸都取自源码实测值，并与真实 App 截图对照。

默认处理（用户未反对）：
- 主机未连接或加载中时，整页只显示一张空状态卡。
- URL 里的提供方不存在，或刚删掉当前选中的自定义提供方时，跳回第一项。
- 已停用的提供方详情照常显示并可编辑，头部徽章显示「已停用」。
