# 05 — ⋯ 菜单、错误卡、继承提示、删除与开关失败

**What to build:** 错误和操作从列表行挪进详情，失败时在原位可见。

- 详情头部（手机在 BackHeader 右侧）加 ⋯ 菜单：DropdownMenu，align end，宽 220。菜单项先放「诊断」，点击暂时打开现有的诊断子弹窗，07 再改成就地；自定义提供方且主机支持 `providerRemoval` 时，加分隔线和 destructive「Remove provider」。删除走现有确认框；成功后按规则回到第一个提供方（栈式回到列表）；失败时在详情顶部显示 Alert error。
- 已启用且出错时，详情最上方显示错误卡：Alert error，标题「{名称} 无法启动」，描述是错误原文（等宽、可选中），actions 是 outline「刷新」和 outline「运行诊断」。「运行诊断」同菜单项。
- 继承 Claude Code 且 Claude Code 启用了第三方接口的自定义提供方，在详情里显示 Alert warning，标题和描述由原来的继承提示拆成两段。
- 列表行去掉错误原文、⋯、「如何安装」链接和继承提示。
- 开关失败时，在列表卡片顶部插一行可关闭的错误，样式同第三方接口区的 actionError 行。
- 提供方列表不再调用 `Alert.alert`。
