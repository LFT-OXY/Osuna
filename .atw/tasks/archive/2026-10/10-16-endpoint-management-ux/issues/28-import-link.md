# 28 — 导入链接

**What to build:** 点别人分享的链接就能添加接口，但先看清风险。

- 桌面端主进程认 `paseo://import?...`（已注册的 `paseo` 链接类型，ADR 0002），交给窗口打开确认框；只有桌面端接收。
- 字段与拒收规则照 magpie `importurl.go`：只收 https，本机与局域网允许 http；地址不带账号、查询串、片段；key ≤ 4096 字节、无控制字符；名称截到 80 字节；模型 ≤ 200 个；未知模板、Vertex、没有任何地址都拒收并说明原因；`gemini` 地址在子任务 7 之前忽略。
- 确认框：「你的对话和这把 key 会发往 {这些地址}，只在信任发链接的网站时添加」；名称和 key 可当场改；替换已有接口另提示。加到这个窗口当前所在的主机；主机没开新能力位时说明要升级。
