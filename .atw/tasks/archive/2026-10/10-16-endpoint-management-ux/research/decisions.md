- 附加请求体：保留字段 `model`、`stream`、`messages`、`input`、`contents`、`system`、`systemInstruction`、`system_instruction`、`instructions`、`tools`；`!name` 强制覆盖，否则只补没有的字段；`${sessionId}` 任意深度替换，取会话头，没有则由首条用户消息推导；测试与检测用 `osuna-test-` 加随机串；只数 token 的请求不带（extrabody.go:6-207）。

2026-10-19 本任务访谈第 2 轮（R2-Qn）：

- R2-Q1 行上「谁会用到这家」：写了「接口标识/模型」的默认模型算那一家；只写模型名的，算顺序最靠前、开着、选了这个模型的那家。行上写「Claude Code、Codex 的默认模型」，点了跳到那个提供方的设置页。
- R2-Q2 模板流程：「+」先出模板列表（搜索；厂商 / 中转服务 / 本机三组；第一项「自定义」即现在的空白表单）；国际站与中国站合成一行，表单里切「国际 / 中国」；有套餐的切「套餐」，切换只保留 key；「去拿 key ↗」跟着区域或套餐变。Bedrock 用 Bedrock API key、不做 AWS 签名、内置模型清单；Azure 用 `api-key` 头、列部署名（presets.go:368-400；azure.go）。图标从 magpie `internal/gui/assets/icons/` 拷来，记进 `THIRD_PARTY_NOTICES`；模型家族已有的图标照旧。
- R2-Q3 服务范围：每家「跟随接口清单 / 只用挑选的」（「只看用量」等子任务 5），取代 R1-Q12 的「新出的模型自动选上」开关。新建默认「跟随接口清单」：去掉没有对应地址的模型后不超过 24 个全用，否则按清单顺序取前 24 个（models.go:26,1458-1468）；已有接口保持「只用挑选的」；从跟随切到挑选时先勾上当前那些。
- R2-Q4 不校验证书：只限「自定义」添加、地址是 https 的接口（insecure_tls.go:8-23）；确认弹窗和行上常驻标记比 magpie 多，保留。
- R2-Q5 测试模型：并发 4、单个 20 秒、整批 3 分钟；发「hi」、回复上限 16；测这家所有在服务的模型；结果只在页面内存里，「能用」用最近一次、没测过的不算失败；「免费」= 模型名或 id 里有独立单词 `free`；「按 Claude Code / Codex 的样子测」用中转站记下的最近一次 CLI 请求头（去掉认证、会话等），存成文件，Claude Code 必须先经过一次中转站（test.go:174-253；test_as.go:14-126）。全局禁用的模型不测。
- R2-Q6 模型设置：模型行菜单打开「模型设置」窗口（显示名、上下文、回复上限、思考档位、能看图、上游模型名、压缩阈值（token 数）、只用这种格式）；接口页另有「整家默认」（上下文、回复上限、压缩阈值、上游模型名，`*` 换成模型 id）。Claude Code 没有显示名与看图的设置项，这两样只对 Codex 与中转站模型列表生效；Codex 没有回复上限的设置项（codexcat.go:121-262；agent/claude.go:249-355）。
- R2-Q7 冷却设置：接口页默认收起的「高级」区；「额度用完后冷却多久」默认 15 分钟（厂商给的时间优先）；「冷却最长多久」默认失败 10 分钟、限流 30 分钟，可选「原因不明的失败不冷却」；范围 0 到 8 天；默认值与现在的 `gateway/cooldown.ts` 常量一致。
- R2-Q8 全局禁用模型：「第三方接口」页底部「已禁用的模型」；完整名或 `*` 通配、不分大小写；从所有模型选单消失、测试跳过；CLI 硬请求时中转站按各格式回 403，写明哪条规则、在哪改（gateway/disabled.go:11-24）。
- R2-Q9 厂商状态页：读 Anthropic（status.claude.com）、OpenAI（status.openai.com）、Moonshot（status.moonshot.cn）的 `/api/v2/summary.json`，DeepSeek 只放链接；只在「第三方接口」页或用量页开着时每 5 分钟看一次；按接口地址主机名对厂商；「价格表自动更新」关着时不看（upstream/upstream.go:43-124）。
- R2-Q10 从别的软件导入：打开「第三方接口」页时后台扫描、最多一分钟一次（CC Switch 数据库、Claude Code `settings.json`（Osuna 接管中读记下的原值）、Codex `config.toml`、Alma 数据库）；OpenCode 只在打开导入窗口时读；提示「发现 N 个本地配置」，可忽略并记住；每条标「新的 / 已添加 / 名称已被占用 / 同一家、key 不同」；操作为新增一家、替换原来那家、就地改名（importapps.go）。
- R2-Q11 导入链接：`paseo://import?...`（ADR 0002 保留 scheme；同时装官方 Paseo 桌面版时系统可能交给它）；字段与拒收规则照 magpie（importurl.go:11-160）；确认框写明对话和 key 发往哪些地址、名称和 key 可当场改、替换已有接口另提示；只有桌面端接收。
- R2-Q12 一个子任务、一条分支，最后合进 main；工单按 7 批：①基础管理（key 选填、复制、排顺序、搜索、行信息、读回 key）②添加（模板、粘贴 curl）③模型清单（保存前拉、合并、每天刷新、丢掉清单、服务范围）④模型信息（模型设置、整家默认、只用这种格式、全局禁用、中转站模型列表能力字段）⑤测试模型与筛选、小标 ⑥连接细节（请求头、附加请求体、key 头、不校验证书、冷却设置、状态页）⑦导入（别的软件、发现提示、导入链接）。
- R2-Q13 界面用词：见 `docs/glossary.md` 本次新增与修改的词条。
