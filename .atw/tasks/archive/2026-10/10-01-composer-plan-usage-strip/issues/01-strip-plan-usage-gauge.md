# 01 — 窄栏常驻显示当前 Agent 提供方的套餐仪表

**What to build:** 桌面端 Agent 面板的 Composer context strip 右侧出现套餐用量分段仪表：第一段是提供方图标加套餐名，后面每个限额窗口一段，显示小圆环、短名、百分比和重置时长。圆环按 tone 变色；会在重置前用完的窗口显示红字「X后用完」。取数没就绪或不适用时，整块不显示，窄栏原有的工作区和分支照旧。窄栏可见时自动取数，挂载拉一次，之后每 5 分钟刷新，倒计时每分钟更新。规格见 `prd.md`（Implementation Decisions 前 9 条，UI and Design），视觉见 `ui-direction.md` 的窄栏一节。

**Blocked by:** None
**Status:** ready-for-agent
**Impl:** done

- [x] 新增窄栏套餐视图模型（纯函数）：输入套餐用量取数结果、当前提供方 id、是否启用第三方接口、当前时间；输出「不显示」或有序分段列表（套餐名段 + 窗口段：短名、百分比、tone、尾部文字、无障碍描述）。余额和明细不进分段
- [x] 「不显示」覆盖：加载中、出错、主机未连接、主机不支持、无该提供方条目、条目状态非 available、没有窗口、启用第三方接口；单元测试逐条覆盖
- [x] 短名按窗口 id 映射：`five_hour` / `session` →「5h」，`weekly` →「周」，`code_review` →「审查」，按模型细分的周窗口只取模型名，未知 id 回退守护进程 label；单元测试覆盖映射与回退
- [x] tone 优先用守护进程下发值，缺失时用客户端兜底；尾部文字规则：有 `runsOutAt` 且有 `shortfallPct` 时显示「X后用完」，到点显示「正在重置」，否则只显示时长；单元测试覆盖
- [x] 套餐用量查询在窄栏可见时启用，每 5 分钟自动刷新，与圆环弹层共用查询键；用真实 `QueryClient` + `QueryObserver` 断言刷新间隔和启用条件
- [x] 新增文案（短名、无障碍描述等）走 i18n，所有语言资源补齐
- [x] e2e（复用套餐用量 fixture）：桌面端 Agent 面板窄栏显示套餐名和三个窗口段；出错、无条目、主机不支持时窄栏没有套餐区；窄栏挂载后发出一次请求
- [x] UI：Agent 面板 / Claude 三个窗口都有数据 / 桌面 1280 — 窄栏右侧依次显示 Claude 图标与 `Max 20x`、`5h`、`周`、模型名三段，窄栏高度仍为 28px，分支名完整
- [x] UI：Agent 面板 / 额度紧张 / 桌面 1280 — 45% 圆环为 statusSuccess，82% 为 statusWarning，93% 为 statusDanger，0% 只有轨道；即将用完的窗口时长位置为红色「1h后用完」
- [x] UI：Agent 面板 / 当前提供方是 OpenCode 或启用第三方接口 / 桌面 1280 — 窄栏右侧没有任何套餐内容，左侧工作区和分支不变
- [x] UI：亮色主题 / 桌面 1280 — 分段仪表配色跟随主题，没有硬编码色值
