# 07 — 会话恢复时的提示怎么改

Type: interview
Status: resolved
Blocked by: 04

## Question

现在 daemon 记录每个 Agent 会话创建时所处的「模式」（官方或某接口），恢复时与当前不同就在时间线上提示（`ApiEndpointModeMismatchSchema`、`api-endpoint-mode-notice.ts`）。改成多接口并存后：

- 会话记录什么：官方 / 接口 id / `slug/模型名`？接口被删除、被暂停、协议改变、模型被取消勾选时各提示什么？
- 自动换家接手的那几轮，时间线上那行「本轮由接口 X 回答」的样子（04 票：只换同名模型，模型不变，所以不提模型），与现有 notification 机制如何复用。
- 老客户端收到新字段怎么降级显示。
- 05 票已定：换不了家时 Agent 收到的报错是「<接口名>: <上游原文>（附重置时间）」，时间线提示不必重复。

产出：Answer 写定提示规则；更新 `prd.md`。

## Answer

访谈两轮（2026-10-14）。第一轮按老设计提出 8 问（恢复时按六种情形提示、改设置当下提示、换家那行、老客户端字段等）；用户指出目标是像 magpie 一样对用户无感——对话照常发请求，中转站自己找该发给哪家，找不到才报错——并说明手机端一直是官方 Paseo App、不改不打包。第二轮按此重问 5 题，全部按推荐。

### 决定

1. **不提示**。恢复旧对话时不做任何检查、不加任何黄条；现有 `api-endpoint-mode-notice.ts`、会话记录里的 `apiEndpointId` 字段及其在 `agent-manager.ts` / `session.ts` 的读写全部删除；协议里的 `apiEndpointModeMismatch` 字段按规矩保留、不再发送。会话不再记「创建时的模式」，它用哪家由它的模型名决定（`slug/模型名` 或光秃秃模型名，见 04 票路由规则）。
2. **接口不可用视同冷却**。对话点名的接口已删除、已暂停、对该 Agent 的开关已关，中转站一律按 04 票的同名换家规则处理：按创建顺序找别家开着、未暂停、未冷却且勾选了同名模型的接口；一家都没有就把报错原样交给 Agent（05 票的包装格式），由 Agent 自己在对话里显示。已暂停的接口点名也不转发。
3. **全关回官方的代价**：某 Agent 开关全关后请求不经中转站，用着接口模型的旧对话会直接收到官方的「模型不存在」报错。接受，同 magpie 关闭后的表现。
4. **换家不加时间线提示**。04 票的「本轮由接口 B 回答」那行不做。Q17 的「输入框上方小横条标出当前实际在用的接口」要不要、怎么做归 08 票；请求对应回具体会话的办法见 `research/session-request-identity.md`（Claude Code 每个请求带 `x-claude-code-session-id`；Codex 带 `thread-id` / `session-id`，兼容旧名 `thread_id` / `session_id` / `x-client-request-id`）。
5. **官方手机 App 是长期用户**，不是过渡期。04 票的老 App 投影从 COMPAT 兼容层改为长期功能，不打清理标记；需求文档写明底线：官方 Paseo App 不改一行、照常能用。
6. **没有新能力标记的客户端只看到光秃秃模型名**（几家都有的去重只出现一次），选了模型按 04 票规则 2 走第一家开着的、勾选了它的接口；手机上不能指定走哪一家。`isModelListAuthoritative` 在任一开关打开时仍为 true。
7. **套餐用量旁的提示**：新客户端只要该 Agent 有任一开关打开就显示「已启用第三方接口，此额度不代表实际消耗」，不点名；老客户端照旧，`activeApiEndpoint` 按 04 票投影（持有默认模型的最早那家）。

### 对其它票的影响

- **04**：「换家那轮时间线提示」与「COMPAT 标签」两处被本票修订；老客户端模型列表只给光秃秃名字是新增投影规则。
- **06**：换家规则里「不可用」的范围扩到已删除 / 已暂停 / 未打开。
- **08**：小横条的取舍归它；官方 App 不改。
- ADR 草稿：不再有「记录会话创建时模式」的消费者，相关段落删去。

## 修订（08 票，2026-10-14）

本票部分结论被 08 票修订（Agent 总开关 + 接口全局开关取代每 Agent 每家开关；「暂停」并入接口开关；一家接口最多三个格式地址 + 自动检测；迁移与老 App 投影相应调整）。以 `map-issues/08-ui-prototype.md` 的 Answer「数据模型修订」与「对其它票的影响」为准。
